# v0.5.53 发布说明

发布日期：2026-10-25

## 核心亮点：反链即时刷新与图文引导空态、邮箱快捷复制微反馈与全场景视觉去噪

依据《UI/UX Pro Max 规范体系》，本版本继续深化反链视窗交互响应力与名册卡片快捷操作体验：

### 1. 反链视窗即时刷新与图文引导空态
- **秒级即时重新扫描**：反链视窗右上角新增 `<RefreshCw>`「刷新反链」动作按钮，带平滑加载旋转动效，写完日记后随手一按，无需重开详情即可原地呈现最新双链与提及条目；
- **优雅图文引导空态**：当尚未记录或过滤无结果时，呈现规整居中的矢量文档图标与清晰的引导说明，视觉层次舒适呼吸。

### 2. 名册卡片邮箱快捷复制与即时微反馈
- 在联系人舒适卡片上，邮箱地址支持便捷复制并伴随 `已复制邮箱 ✓` 绿色即时微反馈（1.5 秒后自动复原），同时无缝兼顾标准桌面邮件客户端调起；
- 卡片生日与周边人脉标签全面去 Emoji 矢量化，统一接入 Lucide `<Cake>` 与 `<MapPin>` 图标。
