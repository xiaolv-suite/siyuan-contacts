# v0.5.45 发布说明

发布日期：2026-10-24

## 核心亮点：全提醒全渠道【不再提醒】全能处置、纪念日免打扰开关与名册复制微反馈

本版本深入回应用户对提醒打扰治理与交互细节的高频诉求，实现了全提醒形态下的“不再提醒 / 稍后处理”全渠道打通：

### 1. 全提醒形态支持【不再提醒】与【稍后处理】全能处置
- **首页行动清单全覆盖**：无论行动卡片是因为生日、久未联系、待办跟进还是重要纪念日，下拉菜单中全量提供：
  - `顺延 3 天` / `顺延 1 周` / `顺延 1 个月`（稍后处理）；
  - `完成跟进（不再提醒）` / `取消计划（不再提醒）`；
  - `今天不再提醒` / `未来 7 天不再提醒` / `不再提醒（永久）`。
- **纪念日免打扰开关 (`remindDisabled`)**：
  - 在联系人详情页的重要纪念日条目上，新增 `🔔 提醒中 / 🔕 不再提醒` 快捷切换开关；
  - 设置为不再提醒后，系统自动在近期提醒、行动清单与雷切动态小组件中彻底过滤该纪念日，杜绝反复弹窗打扰。

### 2. 名册卡片微信号一键复制即时成功微反馈
- 在联系人舒适卡片上，点击微信号复制后，文字即刻平滑切换为绿色的 `已复制微信号 ✓` 成功反馈，保持 1.5 秒后自动复原；
- 极大强化了名册浏览中的物理按压手感与交互确定性。
