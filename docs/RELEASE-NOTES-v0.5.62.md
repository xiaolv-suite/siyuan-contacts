# v0.5.62 发布说明

发布日期：2026-10-26

## 核心亮点：全流程交互连贯性升级、按钮布局逻辑优化与人机工效学体验进化

依据“整理功能交互逻辑，各流程连贯性，各按钮摆放位置合理性，以及整体风格一致性”的产品升维方针，本版本对核心操作链路进行了深度的人机工效学梳理：

### 1. 人机工效学按钮布局与误触防护
- **危险动作空间隔离**：在人物详情页底部操作栏中，将破坏性的「从人脉移除」按钮自动推至最右侧空间隔离，彻底防止在点击“关闭”或“打开文档”时的手滑误触（严格对齐 `destructive-emphasis` 规范）；
- **批量操作唤醒度增强**：名册批量操作工具栏（`.lvct-people__batchbar`）采用暖干邑橙磨砂浮岛高光与自适应微投影，操作感极为醒目；
- **名册卡片快捷动作**：名册卡片右上角动作栏（星标、记互动、图谱、文档）引入轻触按压微缩放与悬浮提亮动效。

### 2. 功能交互与流程连贯性闭环
- **一键触达核心业务**：详情页、名册与横幅条之间的跳转链路平滑自洽，数据状态经由响应式事件总线实现全场景自动同步刷新；
- **交互手感统一**：全插件主按钮、次级外框按钮、文字幽灵按钮、单选/复选框、下拉选择框与胶囊严格遵循物理微触感动效与 8dp 节奏间距。
