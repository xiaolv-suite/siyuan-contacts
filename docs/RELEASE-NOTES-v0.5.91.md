# v0.5.91 发布说明

发布日期：2026-10-27

## 核心亮点：关系图谱交互式边图例动态过滤、测试套件动态通配重构与全依赖升级

本版本深入贯彻落实《小驴人脉后续开发总计划与演进路线图 (2026 - 2027)》第二阶段的关键特性，在关系图谱中落地了交互式边图例动态过滤能力，并重构了工程测试基建与核心依赖：

### 1. 关系图谱交互式边图例动态过滤（RelationGraph）
- **拓扑随心纯化**：在图谱高级工具栏的图例区增设 **直接关系（实线）**、**组织成员（虚线）**、**共同出席（点虚线）** 及 **文档引用（点线）** 独立边图例；
- **即时交互响应**：点击任意边图例项即可秒级在 Cytoscape 画布与文本视图中过滤或恢复对应关系边，无需进复杂设置层反复调整；
- **自适应计数与重置**：过滤状态同步计入生效条件数，支持一键「清除筛选」复原所有可见关系边。

### 2. 测试套件动态通配查找重构与架构守门升级（package.json / architecture.test.ts）
- **告别超长硬编码**：彻底消除 `package.json` 中拼接 103 个具体文件的超长测试指令，升级为现代 Glob 通配匹配 `tests/**/*.test.{ts,mjs}`；
- **守门规则进化**：升级架构分层守门，天然防范新增测试文件遗漏执行的风险。

### 3. 生态工程依赖全量升级
- 安全升级 `@lucide/svelte`（^1.61.0）、`vite`（^8.3.5）、`sass`（^1.106.1）、`svelte-check`（^4.7.7），保障最新构建工具有序运转。

### 4. 双语文档对齐与历史快照规范
- 全面更新 `README.md` 与 `README.en-US.md`，修复此前滞后说明；在历史状态矩阵加盖历史快照章，统一指向最新战略路线图。
