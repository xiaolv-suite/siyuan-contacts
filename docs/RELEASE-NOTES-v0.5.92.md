# v0.5.92 发布说明

发布日期：2026-10-27

## 核心亮点：城市人脉专题文档增量受控刷新（Auto-Rebase）与同城关联机构聚合提炼

本版本深入贯彻落实《小驴人脉后续开发总计划与演进路线图 (2026 - 2027)》第一阶段的关键特性，全面打通了城市专题文档的后台自动增量受控更新机制，并重构了关联机构聚合提炼引擎：

### 1. 城市专题文档增量受控刷新（City Topic Auto-Rebase）
- **后台防抖自动对账**：当联系人常驻城市被编辑、新建或变更时，插件后台自动检测常驻城市的差量变动；
- **智能增量受控刷新**：对于知识库中已建立的城市专题文档（以 `custom-lvct-city` 标识），秒级自动更新其内部的 `custom-lvct-city-contacts` 受控人脉区块，让城市人脉与机构关联常态保持最新；
- **最小侵入守护原则**：对用户尚未主动创建专题文档的城市绝不静默新建文档，用户手写的美食攻略与行程笔记受到 100% 隔离保护，绝不覆盖。

### 2. 同城关联机构聚合提炼高内聚纯函数（extractCityOrganizations）
- **多源智能提炼**：将联系人工作单位、公司、学校及档案 profile 中的机构线索统一收敛为纯函数，自动关联已有的组织实体文档双链；
- **代码重构收口**：消除探索弹窗与后台服务的重复逻辑，实现架构高内聚。
