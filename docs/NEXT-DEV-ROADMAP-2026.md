## 一、当前已交付架构基准（Current Baseline · v0.5.88）

小驴人脉已全面进入 **“独立自主、轻奢质感、深度咬合”** 的成熟期，已完整交付的系统基座包括：

1. **Host Theme Isolation 宿主主题隔离屏障**：
   - 强行接管 `--b3-theme-*` 变量，杜绝思源第三方主题对样式的撕裂与对比度破坏；
   - 确立爱马仕暖干邑橙（`#EA580C`）与绿松石天青灵珠（`#0284C7`）品牌双主色；
2. **人脉关系温度标准五阶色谱**：
   - 温热（暖橙）、常温（翡翠绿）、微凉（落叶金）、渐冻（冰霜蓝）、未互动（冷蓝灰），全生态 100% 呼应；
3. **思源主编辑器「人物 · 组织 · 城市」三位一体浮动档案条（Doc Strip）**：
   - 打开人物文档：展示头像、联系方式、最近互动，高频置顶 `[+ 记互动]` 主按钮；
   - 打开组织文档：展示天青微浮雕徽标、在职归档状态，直达 `[名册成员]` 与 `[组织全景]`；
   - 打开城市文档：展示落叶金微浮雕徽标、常驻好友统计，直达 `[同城好友]` 与 `[行程规划]`；
4. **思源日记与城市实体文档深度双向咬合**：
   - 记互动全链路自动在思源当日日记文档（Daily Note）追加带 `siyuan://blocks/<id>` 的原生双链；
   - 城市正式市级文档受控区块同步，绝不覆盖用户手写的美食攻略与酒店笔记；
   - 城市与行程助手支持商务出差、度假出游、顺路途经等多场景模式自适应切换；
5. **安全与质量铁律**：
   - 纯函数 `domain/` 层零外部依赖；
   - 914 项自动化单测 100% 绿灯；
   - 桌面、390px 移动端视口与思源宿主样式全终端 UI 自动化回归测试持续 488/488 全通。

### 1. 第一阶段：短期聚焦（Near-term / 1~2 周）

#### 1.1 多参与者活动（Occasions）自动在各参与人日记中生成关联记录
- **场景**：一次聚餐（如“大湾区开发者晚餐”）有 4 位好友参加；
- **规划**：在活动保存时，不仅在活动文档与各人物往来记录中打上标记，同时在当天的日记文档中一次性生成清晰的同场出席记录（`- 🍽️ 聚餐：大湾区开发者晚餐（[张三]、[李四]、[王五]）`），使得多维度反链网络彻底贯通。

#### 1.2 城市人脉文档增量受控刷新（City Topic Auto-Rebase）
- **场景**：当某位联系人搬家或修改了常驻城市（例如从北京改为深圳）；
- **规划**：后台防抖检测城市变动，自动更新对应思源城市文档中的受控区块（`custom-lvct-city-contacts`），让城市文档常态保持最新状态，无需手动重复点击同步。

#### 1.3 名册复杂条件流折叠与展开（Active Filter Stream Collapse）
- **场景**：同时激活分组、标签、星标与城市等 4 项以上筛选条件时；
- **规划**：首行展示前 3 项高频胶囊，其余自动收纳为 `+N 项生效条件 ▾` 折叠展开流，右侧保留珊瑚红危险操作 `[清除全部]`，保持名册首屏整洁度。

---

### 2. 第二阶段：中期演进（Mid-term / 1~2 月）

#### 2.1 关系图谱交互式图例切换（Interactive Graph Legend）
- **场景**：在复杂拓扑网络中，用户只想分析纯人物直接关系，不想看到组织连线；
- **规划**：底部图例（实线、虚线、点线）支持直接点选，点击即刻在 Cytoscape 画布中过滤或淡化对应类型的关系边，无需进入设置层反复配置。

#### 2.2 关系图谱节点右侧轻量资料抽屉（Node Quick Drawer）
- **场景**：在浏览力导向图谱时，点击某个节点希望快速查看该人的电话、单位与最近互动，而不打断当前的拓扑探索心流；
- **规划**：支持非跳转模式，右侧滑出轻巧的 320px 资料抽屉，保留全景画布上下文。

#### 2.3 属性视图数据库字段映射“一键自动智能嗅探”（Smart Field Mapping）
- **场景**：新手用户初次绑定已有的思源属性视图数据库；
- **规划**：点击“智能对齐”，插件自动扫描列名中包含“电话/手机”、“微信/Wechat”、“生日/Birthday”等语义特征的列 ID，秒级完成 6 大字段映射配置。

#### 2.4 CardDAV / 本地通讯录协议通道探索
- **场景**：手机通讯录、系统日历与小驴人脉双向流通；
- **规划**：在遵循思源本地优先与隐私保护前提下，提供标准的 CardDAV 服务端点或增量 VCF 轮询通道。

---

### 3. 第三阶段：长期愿景（Long-term / 季度级）

#### 3.1 本地离线智能社交助理（Local AI Copilot）
- **规划**：结合思源笔记内置 AI 或本地 Ollama 模型，在用户记录长段互动备注时：
  - 自动提炼核心事实（如“女儿今年考上了浙大计算机系”、“下个月计划去欧洲旅行”）；
  - 自动沉淀为会前谈资与个性化偏好备忘；
  - 零网络外发、全流程本地安全处理。

#### 3.2 潜在弱联系与共现分析推荐（Graph Analysis）
- **规划**：扫描知识库日记与会议笔记中被频繁共同提及、但尚未在名册中登记为正式双向关系的人物对；
- **输出**：在图谱或设置中提示“发现 3 对潜在同行/好友关系”，用户一键确认即可正式建链。

#### 3.3 跨笔记本与联邦人脉网络穿透
- **规划**：支持多工作空间、多主题笔记本之间的人脉实体互相引用与去重对账，打破单一笔记本边界。

## 三、工程质量与交付规范基准（Quality Assurance Protocol）

后续所有版本的迭代推进，必须严格遵守以下五大铁律：
1. **纯函数分层防线**：所有业务规则、Markdown 渲染、日期解析与图算法严格收敛于 `src/domain/`，零外部依赖；
2. **测试驱动安全网**：单元测试套件必须在 `package.json` 的 `test` 脚本中严格登记，新增能力必须同步覆盖纯函数单测；
3. **全终端 UI 自动化回归闭环**：每个发布候选必须完整通过 Chrome 桌面端、390px 移动端视口与真实思源宿主样式各 **488/488 项自动化回归测试**；
4. **单 Entry 产物铁律**：严禁运行时动态 `import()`，构建单 chunk `dist/index.js`，防范思源内核宿主 loader 崩溃事故；
5. **图标资产守门**：保护 256×256 橙底天青宝珠 `icon.png` 产物大小 ≤ 64KiB 集市限制。
