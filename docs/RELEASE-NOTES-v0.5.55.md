# v0.5.55 发布说明

发布日期：2026-10-25

## 核心亮点：反链智能时序按月分组、块引深度定位链接复制与双向知识图谱深度融合

本版本从深度与广度两个维度，进一步升华知识库笔记反链与人脉资产的双向咬合体系：

### 1. 深度维度：反链视窗按月/按年智能时序分组 (`backlinkMonthGroups`)
- **多反链场景结构化分层**：重度笔记用户在面对数十篇日记引用时，反链列表自动按月份聚合为规整清晰的时序分组（如 `2026年10月（5 条反链）`、`2026年9月（3 条反链）`）；
- **时间脉络一目了然**：配合历史发生时间精准解析，好友在各个历史时期的往来交集层次分明，浏览体验极为流畅。

### 2. 深度维度：单段落思源深度块引用一键复制 (`siyuan://blocks/id`)
- **段落级精准定位**：每条反链卡片新增 **`<Link> 复制块引`** 动作；
- **全生态跨文档跳转**：点击一键复制对应笔记段落的 `siyuan://blocks/${blockId}` 深度链接，在任何随笔、任务或微信汇报中粘贴，点击即可直接穿透回溯当时日记的具体高亮段落，附带 `已复制链接 ✓` 即时成功微反馈。
