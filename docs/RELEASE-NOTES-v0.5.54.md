# v0.5.54 发布说明

发布日期：2026-10-25

## 核心亮点：思源深度块引原生穿透、反链往来双向双链闭环与时间线 Markdown 一键复制导出

本版本进一步打通思源笔记双链知识体系与人脉往来档案的底层深度咬合：

### 1. 正文往来记录思源深度块引穿透 (`siyuan://blocks/id`)
- **双向双链咬合闭环**：反链转录的互动事件，在同步落盘到人物文档正文 `## 往来记录` 时，来源出处自动升级为思源标准深度双链超链接，形如：
  `- 2026-10-24 🤝 见面：和张三讨论了产品规划与技术方案（源自笔记 [《2026-10-24 工作日记》](siyuan://blocks/20261024100000-xxxxxxx)）`；
- **秒级溯源原上下文**：在思源笔记正文中阅读往来履历时，随手一点即可直接跳回写下该事件的原日记具体段落，并自动在原生反链面板中建立双向关系；
- **标准分类补齐**：扩展 `meeting` 与 `email` 标准类型在正文中的语义图标渲染（`🤝 见面` / `✉️ 邮件`）。

### 2. 详情页往来时间线一键导出复制 Markdown
- 详情页“互动”Tab 标题栏右侧新增 **`<Copy> 复制往来记录`** 动作；
- 点击一键将该联系人的历史互动格式化为工整的 Markdown 列表复制到剪贴板，伴随平滑绿色的 `已复制往来记录 ✓` 成功反馈，方便快速粘贴至周报、飞书、微信或复盘笔记中。
