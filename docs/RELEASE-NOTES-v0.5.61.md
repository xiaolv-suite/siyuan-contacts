# v0.5.61 发布说明

发布日期：2026-10-26

## 核心亮点：全景像素级 UI/UX 巅峰重塑——自主品牌色彩、按压微触感动效与全场景轻奢质感

依据用户“UI 不用跟宿主主题适配，按照插件自己的品牌设计语言来就行”的统领方针，本版本对全插件每一个页面、每一个弹窗、每一个窗口、每一个按钮、每一个卡片、每一个胶囊、每一个图标与交互微动效进行了**全景像素级重塑**：

### 1. 全局品牌设计系统深化（Tokens & Isolation）
- **核心色阶统合**：暖干邑橙（`#EA580C`，次级 `#C2410C`，悬浮微底）作为主行动力与品牌高光，天青灵珠（`#0284C7`）作为知识双链连接专属色，琥珀金作为重要纪念日专属色；
- **自控多层深邃阴影**：卡片拥有自然漫反射阴影与 1px 微内发光高光（`inset 0 1px 0 rgba(255,255,255,0.85)`），卡片浮层质感超越原生；
- **暗黑沉浸式曜石黑**：深色模式全面对齐 Slate-900 / Slate-800 优雅色阶与 `#F8FAFC` 纯净文字。

### 2. 公共控件层全景重塑（Controls & Micro-interactions）
- **全系列按钮物理微触感**：主按钮、次级外框按钮、文字幽灵按钮均注入 `active: translateY(1px) scale(0.975)` 物理按压反馈，手感极佳；
- **胶囊（Chip）与标签体系重构**：统一圆角 `9999px`，文字对比度均严格 `≥ 7:1`，悬浮与点选平滑微发光；
- **输入框与下拉选择框**：统一 6px 优雅圆角，内凹微阴影，获得焦点时平滑扩散暖干邑橙呼吸光环。

### 3. 页面级与弹窗全景细节精修
- **首页仪表盘**：里程碑金橙微渐变横幅、统计卡片悬浮立体微上浮、周度日程滑轨药丸排版与行动清单；
- **名册卡片网格**：PersonCard 微浮雕卡片、分组头像渐变色阶、微信/电话/邮箱一键快捷复制微反馈；
- **人物详情弹窗**：英雄卡头图排版、TabList 橙色下划线动效、五维档案折叠面板与反链视窗 Bento 瓷贴。
