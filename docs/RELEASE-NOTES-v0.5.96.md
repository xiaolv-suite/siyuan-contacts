# v0.5.96 发布说明

发布日期：2026-10-27

## 核心亮点：多主题色彩方案系统（Theme Color Schemes）与全景色调随心切换

本版本深入贯彻用户个性化与美学自洽需求，上线了多款高阶主题色彩方案与实时调色盘切换系统：

### 1. 打造 5 大专属主题色彩体系（Theme Color Schemes）
- 🧡 **暖干邑橙（Cognac Orange · 默认推荐）**：爱马仕轻奢暖橙（`#EA580C`）配绿松石天青宝珠（`#0284C7`），温润而具人际温度；
- 💚 **生机翡翠（Emerald Jade）**：清新典雅翡翠绿（`#059669`）配落叶金（`#D97706`），彰显常青人脉与健康活力；
- 💙 **深海蔚蓝（Deep Ocean Blue）**：现代克制商务蓝（`#2563EB`）配松石青（`#0D9488`），严谨理性，契约感十足；
- 💜 **极光紫罗兰（Royal Amethyst）**：深邃灵动极光紫（`#7C3AED`）配玫瑰粉（`#DB2777`），绮丽典雅，艺术感拉满；
- 💛 **暗金落叶（Amber Gold）**：沉稳内敛琥珀金（`#D97706`）配天青灵珠（`#0284C7`），岁月沉淀，经典不凡。

### 2. 设置页即时调色盘点选与全景自洽联动
- **秒级即时预览**：在设置页“通用偏好”区增设专属色盘，用户点击任意色块，整套界面与设置页本身即刻实时变色；
- **令牌层级联动**：基于 `[data-lvct-theme]` 属性接管设计令牌（Design Tokens），全局卡片高光、微浮雕、阴影、图谱边及状态胶囊 100% 自动派生，完美自洽，跨会话持久化保存。
