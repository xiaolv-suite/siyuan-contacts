# v0.5.72 发布说明

发布日期：2026-10-26

## 核心亮点：全景设计规范方案落地——日期快捷胶囊、行动就地闭环与组织看板平滑卷入

本版本正式落地《全景 UI/UX 深度审查报告与系统性优化方案》第一阶段与第二阶段之核心人机工效学改进：

### 1. 快捷记互动增设 `[今天 / 昨天 / 前天]` 快捷日期点选
- **告别频繁点选日历**：在 `QuickRecordDialog` 日期输入框右侧增设自控高光微胶囊 `[今天]` `[昨天]` `[前天]`；
- **补录交往事实秒级完成**：用户补录前两天的交往谈话，一键轻点即自动切换发生日期，免去弹开原生笨重日历选择器的繁琐交互。

### 2. 首页行动清单增设就地「记一笔互动」直达
- **流程闭环**：在首页仪表盘行动清单（Action Row）的更多处置菜单中，新增高亮主操作 **`[记一笔互动]`**；
- **业务秒级对齐**：处理待办跟进时，用户无需在多层界面间来回跳转，就地一键唤起记互动流程。

### 3. 组织看板点击卡片平滑卷入视窗（`auto-scroll into view`）
- **空间秩序自然舒展**：在组织全景视图（`OrgsView`）中，当组织卡片较多时，点击某张卡片，下方展开的成员架构看板自动平滑卷动居中展现在可视区，省去反复手动下划滚轮的疲劳。

### 4. 名册卡片单位超长自动截断与原生气泡（`line-clamp: 2`）
- **网格高度整齐划一**：名册卡片长单位名称最多限制展示 2 行并附带完整标题原生 tooltip，彻底杜绝超长单位撑破卡片栅格整齐度。
