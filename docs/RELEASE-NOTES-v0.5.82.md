# v0.5.82 发布说明

发布日期：2026-10-26

## 核心亮点：思源文档融合深化——文档档案条（Doc Strip）视觉重塑、主操作置顶与微触感反馈

本版本继续围绕用户“继续优化，继续强化与思源文档的融合”之核心演进方向，全面重塑了思源主编辑器人物文档档案条（Doc Strip）的视觉体系与人机交互：

### 1. 文档档案条视觉质感重塑（Doc Strip）
- **Squircle 暖橙渐变微浮雕头像**：标题下方注入的浮动档案条头像由旧单色背景全面升级为与主名册一致的 Squircle 暖干邑橙渐变配白光立体微投影；
- **徽章色阶全面自洽**：分组（暖干邑橙）、生日（落叶金）与最近互动（翡翠绿）全面接入标准自控色阶；
- **复制联系方式微触感光环**：点击复制电话/微信/邮箱后，芯片呈现翡翠绿光环（`box-shadow: 0 0 0 2px color-mix(in srgb, var(--lv-heat-warm) 28%, transparent)`）微动效。

### 2. 「记互动」按钮升级为 Primary 主行动点
- **阅读笔记时一秒直达**：在档案条右侧操作区，将高频核心操作「记互动」由普通灰色微按钮升级为醒目的 Primary 暖干邑橙主按钮，用户在思源正文中读到朋友笔记时，一眼抓取核心动作入口，记录交往事实无任何心智摩擦。
