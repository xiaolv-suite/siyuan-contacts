# v0.5.59 发布说明

发布日期：2026-10-25

## 核心亮点：多级目录日记智能时间解析、往来历史「🔗 原文」块引用一键溯源与双向穿透

本版本进一步强化知识库深层层级目录结构下的历史时间还原能力，并打通入库时间线与原笔记段落的双向溯源：

### 1. 深度维度：多级层级路径日历日期智能提取
- **复杂目录结构全覆盖**：增强 `parseBacklinkOccurredTime` 解析引擎，支持形如 `/日记/2026年/10月/24日/随笔`、`/Daily/2026/10/24/note` 等多级层级路径，无惧深度嵌套目录；
- **真实历史时间还原**：即使用户的日记文档标题仅命名为“随笔”、“工作小记”或未命名，也能准确还原发生历史日期，避免时间线失真。

### 2. 深度维度：时间线转录条目「🔗 原文」块引深度链接一键复制
- **历史记录无缝溯源**：在详情页互动往来时间线上，对所有由反链转录入库的事件，新增轻量级 **`[🔗 原文]`** 按钮；
- **段落级穿透跳转**：点击一键复制对应笔记段落的 `siyuan://blocks/${id}` 深度块引定位链接，并伴随平滑绿色的 `已复制` 即时反馈，随时精准直达当时写下该事件的原日记段落。
