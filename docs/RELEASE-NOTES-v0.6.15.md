# v0.6.15 发布说明

发布日期：2026-10-28

## 核心亮点：名片语义智能画像标签自动推断（Persona Tag Inference Engine）

本版本深入贯彻落实小驴快门中枢 Issue #146 第二批社区顶尖方案（借鉴：自动打分类标签 AutoTag 的大模型与语义层级推断机制）的落地建议，解决“用户录入联系人资料后经常不知道打什么标签、日后人脉库庞大时无法精细分类筛选”的核心痛点：

### 1. 纯本地语义层级智能推断引擎（inferPersonaTags）
- **多维度深度语义挖掘**：纯函数零外部依赖，自动聚合分析联系人的职务背景（`profile.work`）、所属组织、常驻城市、往来备忘与谈资画像；
- **标准化多层级画像标签输出**：
  - **行业领域**：`#行业/人工智能`、`#行业/云计算`、`#行业/软件科技`、`#行业/金融投资`、`#行业/医疗健康`、`#行业/高等教育`、`#行业/法律合规`、`#行业/先进制造`；
  - **职业身份**：`#身份/创始人合伙人`、`#身份/技术管理`、`#身份/专业顾问`；
  - **生活与偏好**：`#偏好/品茶`、`#偏好/精品咖啡`、`#偏好/户外运动`、`#偏好/饮食注意`；
  - **常驻地域**：`#地域/深圳`、`#地域/北京` 等；
- **智能去重与过滤**：自动排除当前人物名下已有的同名标签，精准呈现增量建议。

### 2. 详情页与编辑弹窗双向协同采纳
- **详情页实时建议呈现**：在联系人详情页（`PersonDetail`）的标签一栏，实时展示由谈资事实与职业推导出的建议标签芯片，点击可直接激活编辑；
- **编辑弹窗一键采纳**：在资料编辑弹窗（`PersonEditDialog`）中，点击任一推断标签芯片即可瞬间追加，并支持 **「+ 采纳全部建议标签」** 批量一键归类，人脉分类与精准检索效率极大飞跃。
