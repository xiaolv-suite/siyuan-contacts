# v0.5.60 发布说明

发布日期：2026-10-26

## 核心亮点：宿主主题隔离屏障、独立自主设计语言重塑与全场景高阶质感梳理

依据最新产品设计决策（“UI 不用跟宿主主题适配，按照插件自己的品牌设计语言来就行”），本版本在全插件域内建立完全自主、高度自洽、不受第三方主题恶性污染的独立视觉闭环：

### 1. 建立 Host Theme Isolation（宿主主题隔离屏障）
- **摆脱第三方主题绑架**：在 `.lvct-tab-root`、`.lvct-dialog-root`、`.lvct-doc-strip` 与 `.lvct-workbench` 根域内，全面接管并重定向 `--b3-theme-*` 宿主主题变量；
- **全自主品牌呈现**：无论用户在思源笔记中换了什么透明、高对比度或杂乱第三方主题，小驴人脉始终呈现自主稳定的暖干邑橙（`#EA580C`）与天青灵珠（`#0284C7`）轻奢视觉系统；
- **暗黑曜石质感升级**：深色模式全面采用沉浸式 Slate-900 / Slate-800 曜石底色与 `#F8FAFC` 纯净文字，彻底告别低对比度脏灰色。

### 2. 全方位梳理核心控件与卡片设计规范
- **工作台主导航项重构**：激活项采用小驴暖干邑橙专属药丸高亮与微内高光描边，与左侧品牌 LOGO 遥相呼应；
- **全插件卡片统一微浮雕**：统计卡片、名册卡片与组织看板统一接入自控背景、柔和边框与悬浮微浮雕投影；
- **核心控件高质感梳理**：输入框采用焦点品牌呼吸环，胶囊（Chip）采用自控圆角与高对比度配色体系。
