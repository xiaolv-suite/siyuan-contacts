# v0.5.63 发布说明

发布日期：2026-10-26

## 核心亮点：页面布局网格自适应重塑、周度滑轨空间秩序梳理与多端分屏响应式跃迁

本版本依据“继续优化 UI 设计，梳理页面布局”的核心指导方针，对全插件桌面多栏、分屏与移动端布局进行了**空间秩序重塑**：

### 1. 首页仪表盘核心图表区网格自适应（`lvct-dash__charts-grid`）
- **告别分屏布局崩塌**：将原有在 960px 处硬编码突兀换行的固定网格，升级为智能自适应流式网格：
  `grid-template-columns: repeat(auto-fit, minmax(min(100%, 260px), 1fr)); gap: 16px;`；
- **自适应任意分屏宽度**：无论用户将小驴人脉放置在全屏、左右双分屏（600px ~ 800px）还是侧边栏浮动窗口中，温度分布、近期走势与出差规划三张卡片均能自动按当前可用空间优雅排布为三列、两列或单列，杜绝文字挤压与边界溢出。

### 2. 周度 7 天时序滑轨空间秩序梳理（`lvct-week-glance`）
- **文字与色彩层级自控**：全面替换滑轨中依赖宿主主题的变量，改用自控 `--lv-brand` 暖干邑橙、`--lvct-text-1` 与 `--lvct-text-2`；
- **指示圆点与对焦点排版规范**：滑轨药丸内部的星期、日期与事件指示点（生日与跟进）严格居中对齐，今日药丸与选中药丸对比度高雅清晰。
