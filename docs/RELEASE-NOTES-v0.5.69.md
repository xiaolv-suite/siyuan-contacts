# v0.5.69 发布说明

发布日期：2026-10-26

## 核心亮点：逐页面用户体验升维——图谱证据卡弹性舒展、周度滑轨即时反馈与多页面微交互闭环

本版本严格贯彻用户“从用户使用的角度，挨个页面进行一下优化”之核心方针，逐个页面站在用户日常真实高频操作路径中进行体验精修：

### 1. 首页仪表盘（DashboardView）
- **周度滑轨日程安排色阶与视觉对齐**：滑轨展开栏中的生日与待办条目全面升级为自控 `--lv-heat-cool`（落叶琥珀金）与 `--lv-brand`（暖干邑橙），增加平滑内边距与清晰圆角；
- **空态关怀引导**：今日待办全部安顿完成时，平滑呈现「浏览联系人」与「开启交往回顾」双向行动建议，体验自然舒展。

### 2. 关系图谱（RelationGraph）
- **连接证据卡片弹性舒展（Hover Evidence Card）**：将画布悬浮卡片宽度从原先狭窄的 220px 扩展至自适应 `min(280px, calc(100% - 24px))`；
- **丰富关系信息一目了然**：多共同组织、长姓名与同场出席次数不再被强制折行截断，并加入 pop-in 微动效，鼠标滑过即可清晰阅览。

### 3. 名册与组织视图（PeopleView & OrgsView）
- **A-Z 索引条与部门导航**：字母索引栏高亮与组织部门筛选 Chip 统一采用小驴品牌色阶，悬浮与点选反馈即时明确。
