# v0.5.67 发布说明

发布日期：2026-10-26

## 核心亮点：全插件色彩体系大一统、人脉温度高质感色谱与全场景色彩匹配度跃迁

本版本严格贯彻用户“梳理整个插件的颜色体系，提升颜色质感与匹配度，梳理全部颜色的应用”之核心指令，对插件全生态色彩系统进行了**结构性的大一统与质感跃迁**：

### 1. 建立标准人脉关系温度高质感色谱（`--lv-heat-*`）
- **根治三套色彩冲突与割裂**：彻底纠偏此前在温度条、温度胶囊与温度徽章中存在的色彩倒挂（如旧代码曾把渐冻误写为红色、常温误写为灰色）的严重不一致；
- **五阶标准色阶统合**：
  - 🔥 **温热（Hot）**：暖干邑橙（`#EA580C`，暗色 `#F97316`，微底 `14%`）
  - 🌿 **常温（Warm）**：生机翡翠绿（`#16A34A`，暗色 `#4ADE80`，微底 `14%`）
  - 🍂 **微凉（Cool）**：落叶琥珀金（`#D97706`，暗色 `#FBBF24`，微底 `14%`）
  - ❄️ **渐冻（Cold）**：冰霜天青蓝（`#0284C7`，暗色 `#38BDF8`，微底 `14%`）
  - ⚪ **未互动（Muted）**：雅致冷蓝灰（`#64748B`，暗色 `#94A3B8`，微底 `12%`）
- **全生态 100% 呼应**：温度直方条（`.lvct-heat-bar__segment`）、仪表盘微胶囊（`.lvct-chip`）、行动卡片标签（`.lvct-action-chip`）与人物详情徽章（`.lvct-heat`）全部严格统一消费该令牌体系。

### 2. 现代高阶分组调色盘升级（`--lvct-group-*`）
- 升级家人（珊瑚绯红 `#E11D48`）、朋友（翡翠明绿 `#059669`）、同事（商务天蓝 `#2563EB`）、同学（丁香优雅紫 `#7C3AED`）、组织（绿松石青 `#0D9488`）与其它（中性冷灰 `#64748B`）；
- 暗色模式下精准优化饱和度与发光感（如 `#FB7185`、`#34D399`、`#60A5FA`），彻底杜绝灰浊感。
