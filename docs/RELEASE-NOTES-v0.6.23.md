# v0.6.23 发布说明

发布日期：2026-10-28

## 核心亮点：相关人面板「潜在交集伙伴与一度破冰引荐」（Co-occurrence & Mutual Ties Recommender）

本版本全面兑现第二阶段 E-34 弱联系共现发现与破冰引荐规划，将深层社交交集与一度好友引荐直接无缝融入人物详情页相关人视窗：

### 1. 深度人脉交集与破冰引荐挖掘算法（`discoverPersonTies`）
- **多维度弱连接推算（纯函数，零外部依赖）**：
  - 🤝 **共同出席（Co-attendance）**：基于同场活动、会议与聚会历史，客观挖掘频繁同场但未正式建链的潜在伙伴；
  - 🏢 **共同机构（Shared Affiliations）**：基于组织归属、工作经历与公司信息推断相同从业背景；
  - 👥 **共同好友（Mutual Connections）**：精准识别两位联系人共同认识的一度好友，提供可靠的破冰引荐人纽带；
- **智能打分与理由解释**：按同场频次、组织交集与共同好友综合加权，生成可解释性极强的推荐理由标签（如：“共同出席 2 次活动”、“共同机构：星河科技”、“共同好友：王五”）。

### 2. 详情页相关人面板潜在伙伴推荐卡片（`PersonDetail.svelte`）
- **心流不中断的发现视窗**：在相关人列表与关系雷达下方优雅展示「💡 潜在交集伙伴（推荐建立关联）」；
- **一键建立双向关联**：点击 **`[+ 建立关联]`** 即可直接调用数据库与文档区块同步管道，自动为双方建立正式双向关联；
- **名片穿透与平滑导航**：点击推荐伙伴姓名即可平滑切入对方人物画像，探索社交网络如同穿针引线般流畅自然。
