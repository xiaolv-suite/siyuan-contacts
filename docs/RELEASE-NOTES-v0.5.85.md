# v0.5.85 发布说明

发布日期：2026-10-26

## 核心亮点：设计方案深化落地——合并向导「保留两者」交互增设与完全自洽微浮雕

本版本继续围绕用户“继续”之核心演进方向，全面落实《全景 UI/UX 深度审查报告与系统性优化方案》中关于重复联系人字段级安全合并向导的交互升维与视觉自洽：

### 1. 合并向导增设「保留两者」一键合并能力（ContactMergeWizard）
- **告别非此即彼的覆盖顾虑**：当待合并的主次联系人均登记了有效联系方式（如不同手机号或邮箱）时，在选择行直接提供轻巧的 **`[保留两者]`** 快捷微胶囊；
- **零信息损失合并**：点击一键自动生成顿号分隔的自定义值（如 `13800000001、13900000002`），有效电话与微信全部保全，消除重复合并时的手打拼合摩擦。

### 2. 字段比对表格小驴自控微浮雕与深色自洽
- **清除宿主杂乱边框**：全面移除组件内硬编码的 `--b3-border-color` 与 `--b3-theme-*` 变量；
- **小驴自控微浮雕规范**：表头接入 `--lvct-bg-app` 柔和底色，字段行改用轻量边框，预览区引入 `box-shadow: inset 0 1px 0 rgba(255, 255, 255, 0.4)` 内高光微浮雕，深浅模式下均清爽雅致。
