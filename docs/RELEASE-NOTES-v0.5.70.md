# v0.5.70 发布说明

发布日期：2026-10-26

## 核心亮点：逐页面用户体验深度升维——名册星标矢量高光、组织搜索一键新建与图谱恢复强引导

本版本严格遵循“从用户使用的角度，挨个页面进行一下优化”之统领要求，深入到名册、组织与图谱每一个实际操作环节进行实打实的交互减阻：

### 1. 联系人名册页面（PeopleView）
- **分组胶囊星标常用矢量化**：快捷分组栏中的 `⭐ 常用` 彻底淘汰系统彩色 Emoji，升级为与微按钮联动的单色矢量 `<Star>` 图标，选中时呈现纯白高光与立体投影；
- **分组胶囊样式完全自洽**：移除依赖宿主主题的旧变量，全面消费小驴自有 `--lv-brand` 暖干邑橙，悬浮与点选过渡自然。

### 2. 组织全景视图（OrgsView）
- **搜索无匹配一键新建**：当用户按名称搜索组织未命中时，空态区域不仅提供“清除筛选”，还智能提供高亮主操作 **`[+ 新建组织（当前搜索词）]`**，无需清空输入框再点外部新建，大幅缩减操作步骤。

### 3. 关系图谱页面（RelationGraph）
- **空态恢复强引导**：图谱在无节点或筛选后空态下，将「清除筛选」提升为 Primary 暖干邑橙主按钮，提供清晰的视觉恢复抓手。
