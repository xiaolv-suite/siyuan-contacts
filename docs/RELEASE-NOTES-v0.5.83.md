# v0.5.83 发布说明

发布日期：2026-10-26

## 核心亮点：思源文档融合深化——组织文档专属浮动档案条（Doc Strip）与成员筛选直达

本版本继续围绕用户“继续优化，继续强化与思源文档的融合”之核心演进方向，全面打通了思源主编辑器组织实体文档的顶部控制生态：

### 1. 组织文档专属浮动档案条（Organization Doc Strip）
- **组织文档智能识别与挂载**：用户在思源笔记中打开任何一篇组织文档（如《未来科技》、《大湾区创新中心》）时，标题下方自动注入组织专属浮动档案条；
- **天青灵珠企业级徽标**：图标采用天青渐变配白光立体微浮雕（`lvct-strip__avatar--org`），直观呈现组织名称与归档状态；
- **双向枢纽无缝流转**：
  - **`[名册成员]`**（Primary 暖橙主操作）：点击秒级拉起小驴人脉工作台并在名册中精确筛选属于该机构的全体成员；
  - **`[组织全景]`**：点击一秒直达小驴人脉组织全景工作台，查看架构看板与部门分布。
