# v0.5.68 发布说明

发布日期：2026-10-26

## 核心亮点：全场景杂色清剿、分组头像渐变色纯化与品牌色阶无缝融合

本版本深入贯彻用户“不要有不协调的部分”的严格色彩美学指导方针，对全插件出现的每一处残存杂色与硬编码颜色进行了地毯式清剿：

### 1. 全场景杂色清剿与品牌色阶统合
- **根治 Bento 卡片杂乱撞色**：彻底移除统计卡片与横幅中历史残留的芭比粉（`#ec4899`）与深紫（`#8b5cf6`），全面收敛为暖干邑橙（`#EA580C`）、天青灵珠（`#0284C7`）、琥珀落叶金（`#D97706`）与珊瑚红（`#E11D48`）组成的典雅四色高光体系；
- **旧鸭羽绿彻底退役**：清理 `_tokens.scss` 中残留的 `#129e9a`、`#0f9d98`、`#51cfc4` 等旧色系变量，将品牌基础色阶全面收敛至爱马仕暖干邑橙。

### 2. 分组头像渐变配方纯化（color-mix 动态派生）
- **告别硬编码杂乱色**：彻底重构名册卡片头像（`lvct-person-card__avatar`）、详情页头像（`lvct-detail__avatar`）与仪表盘头像（`lvct-dash__person-avatar`）的背景渐变；
- **自适应高阶派生**：统一采用 `color-mix(in srgb, var(--lvct-group-*) 78%, #ffffff)`，使头像高光背景与分组徽章的颜色 100% 动态匹配且浑然一体，在深浅模式下均保持极致和谐与高对比度。
