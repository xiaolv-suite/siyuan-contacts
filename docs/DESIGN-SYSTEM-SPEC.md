## 3. 宿主主题隔离机制（Host Theme Isolation Shield）

在 `.lvct-tab-root`、`.lvct-dialog-root`、`.lvct-doc-strip` 与 `.lvct-workbench` 根域内，强行接管并重定向 `--b3-theme-*` 变量至小驴自有令牌，确保无论外部主题如何怪异，插件内部的卡片、输入框、按钮与文字永远维持在 7:1 以上的超高清晰对比度。

## 4. 人机工效学与交互原则（Ergonomics & Interaction Guidelines）

### 4.1 破坏性操作空间隔离（Destructive Separation）
- 在人物详情等关键视窗中，破坏性的「从人脉移除」按钮自动通过 `margin-left: auto` 推至最右侧空间隔离，防止在点击“关闭”或“打开文档”时的手滑误触（对齐 `destructive-emphasis` 规范）。

### 4.2 键盘优先与无障碍直达（Keyboard First）
- **名册全局按键**：名册页全局监听键盘 `/` 按键，未聚焦在输入框时轻轻一按立即秒级平滑聚焦搜索框并全选文本；`Esc` 一键清空；
- **快速保存**：弹窗表单统一支持 `Ctrl+Enter` 快速落盘保存，`Esc` 退出。

### 4.3 物理按压微触感动效（Tactile Feedback）
- 按钮统一注入 `active: translateY(1px) scale(0.975)` 物理微触感与平滑过渡；
- 浮层与菜单统一注入 `lvct-pop-in`（`scale(0.96) translateY(-4px) → normal`）弹性入场动效。

## 5. 五大核心页面布局架构梳理（Page Layout Architecture）

| 页面 | 核心布局架构 | 空间秩序与自适应规则 |
| :--- | :--- | :--- |
| **首页仪表盘**<br>`DashboardView` | 激励横幅 + 4维统计卡片 + 核心图表网格 + 7天时序滑轨 + 行动清单 | 核心图表区采用 `repeat(auto-fit, minmax(260px, 1fr))` 流式网格，自适应任意分屏与窗口宽度；时序滑轨展开栏就地提供生日与跟进直达。 |
| **联系人名册**<br>`PeopleView` | 搜索栏 + A-Z 拼音跳跃条 + 快捷分组栏 + 条件流 + 卡片/表格切换 | 卡片栅格采用 `auto-fill minmax(270px, 1fr)` 搭配 `scrollbar-gutter: stable` 彻底杜绝滚动闪烁；搜索无结果一键以当前搜索词新建联系人。 |
| **关系图谱**<br>`RelationGraph` | 模式工具栏 + 范围与中心控制台 + 画布悬浮控制岛 + 节点浮层证据卡 | 悬浮证据卡（Hover Evidence Card）扩展至 280px 弹性宽度并注入 pop-in 动效；空态清除筛选提升为 Primary 主操作。 |
| **组织全景**<br>`OrgsView` | 组织总览统计条 + 状态筛选 + 组织卡片看板 + Master-Detail 成员架构看板 | 成员网格采用 `auto-fill minmax(200px, 1fr)` 弹性栅格；搜索无结果空态就地提供新建组织直达主操作。 |
| **设置与维护**<br>`SettingsView` | 左侧设置子导航栏 + 右侧独立设置面板卡片 | 内容面板内边距提升至 28px 呼吸留白，子导航项采用暖干邑橙激活药丸，体检修复与数据库核对流程具备清晰的说明引导。 |
