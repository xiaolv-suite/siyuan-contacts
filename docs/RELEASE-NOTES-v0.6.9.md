# v0.6.9 发布说明

发布日期：2026-10-27

## 核心亮点：仪表盘行动卡直达记互动、原因分类图标胶囊与潜在关联下钻互通

本版本深入贯彻落实《小驴全生态联邦协同与排雷规范》关于人机工效学与轻奢 Bento 美学的要求，全面优化了仪表盘今日行动与潜在关联发现交互：

### 1. 今日行动清单直达记互动与分类图标微胶囊
- **就地直达记互动**：行动卡更多菜单中的 **`[记一笔互动]`** 操作，升级为直接唤起该人物的往来互动时间轴与记录视窗（自动激活 `activity` tab），免去用户打开详情后再手动切页的繁琐步骤；
- **Bento 分类图标微胶囊**：行动原因标签前置引入直观图标标识（🎂 生日、💍 纪念日、📌 待办跟进、💬 保持联络），视觉感知更清晰生动。

### 2. 潜在人脉关联发现支持下钻人物详情与名册定位
- **人物卡片点击下钻**：潜在关联发现面板中，好友卡片升级为可交互按钮，点击任一人物头像或姓名即可瞬间唤起详情视窗预览其背景与资料；
- **名册定位快速对比**：新增 **`[名册定位]`** 快捷按钮，点击直接在名册中按 itemID 筛选出当前候选的两位好友进行资料比对，全流程严密可控。
