# v0.5.93 发布说明

发布日期：2026-10-27

## 核心亮点：关系图谱节点右侧轻量速查抽屉（Node Quick Drawer）与轻奢 Bento 微触感

本版本深入贯彻落实《小驴人脉后续开发总计划与演进路线图 (2026 - 2027)》第二阶段的核心特性，在关系图谱中上线了右侧轻量速查抽屉，实现全景探索与资料速查的无缝共存：

### 1. 关系图谱节点右侧轻量速查抽屉（Node Quick Drawer）
- **心流不中断**：点击画布上的人脉或组织节点，右侧自适应滑出 320px 轻量抽屉，告别生硬大弹窗遮挡画布；
- **核心资料一览**：即时展示姓名、分组、常驻城市、归属单位及图内连接度数；
- **一键复制与微反馈**：电话、微信、邮箱均支持一键复制，带有翡翠绿微触感对勾反馈；
- **多维快捷动作**：置顶「完整档案 ↗」（直达完整资料编辑）与「打开文档 ↗」（主编辑器直达），支持点击空白画布或 Esc 键丝滑收起。

### 2. 轻奢 Bento 微浮雕与滑入动效
- **高阶美学**：抽屉采用小驴自控卡片内高光、柔和环境光遮蔽阴影与圆角设计，深浅色主题下均优雅协调；
- **组织节点支持**：点击组织节点同样支持滑出组织概况与「组织全景」快捷入口。
