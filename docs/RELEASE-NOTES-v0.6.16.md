# v0.6.16 发布说明

发布日期：2026-10-28

## 核心亮点：局部社交关系网微雷达（Mini Relation Radar Topology）

本版本深入贯彻落实小驴快门中枢 Issue #146 第一批社区顶尖方案（借鉴：双链图谱 / KMind 关系微型拓扑呈现）的指导建议，为联系人详情抽屉增设了以人物为核心的局部社交关系网微型拓扑雷达：

### 1. 局部人脉拓扑星系雷达图（MiniRelationRadar）
- **核心人物环形星系辐射布局**：
  - 基于纯函数 `domain/radar-topology.ts`，自动以当前人物为原点，均匀计算周围 1 度与直接相关好友的轨道坐标；
  - 纯 SVG 矢量渲染，高反差光晕、动态脉冲虚线轨道与高亮连线；
  - 中心展示核心人物暖干邑橙专属徽标与姓名；
- **微交互与平滑穿透**：
  - 鼠标悬停任意周边好友节点，连线与节点自动高亮聚焦；
  - 点击雷达网络中的任一相关人节点，平滑穿透唤起该好友的专属详情视窗，多层人际网络穿梭直观高效；
- **双模态自由切换**：
  - 在相关人视窗顶部提供 **`[📡 关系雷达]`** 与 **`[📋 清单]`** 双模态点选切换，兼顾拓扑视觉分析与传统清单管理。
