# v0.5.47 发布说明

发布日期：2026-10-25

## 核心亮点：双链转互动深度优化——还原历史真实时间、语义智能推断与内容纯净提炼

针对用户提出的“双链转为互动要按照当时双链的时间，而非现在转入的时间，继续深度优化转换的内容”的核心诉求，本版本彻底重构并升级了反向链接转录引擎：

### 1. 发生时间精准还原引擎 (`parseBacklinkOccurredTime`)
- **还原历史真实时间**：告别原先统一标记为“今天/当前时间”的失真问题，系统严格按照当时双链发生的时间写入互动：
  1. **日记日期优先识别**：智能解析 Daily Note / 每日随笔文档标题与路径中的明确日期（如 `2026-09-18 工作日记`），精准将互动锚定在日记对应的历史发生日；
  2. **块真实创建时刻（`created`）**：若标题无日期，则精确回退至思源块创建的历史时间戳（`yyyyMMddHHmmss`）；
  3. **时分秒自然继承**：若块在当天 14:30 记录，互动时间戳严格继承 14:30，绝不丢失时间精度；
- **真实时间线重定位**：转录后的历史事件自动插入好友往来时间线（Timeline）对应的历史月份与年份中，人脉文档正文 `## 往来记录` 同步精确归档，不再破坏久未联系与关系温度的真实节奏。

### 2. 转换内容智能提炼与清洗 (`cleanInteractionNote`)
- **双链语法无损净化**：自动清洗思源内部代码 `((id "张三"))`，消除生硬的技术括号；
- **杂质符号剥离**：自动清除行首列表符（`- `、`* `、`1. `）、引用符（`> `）以及待办任务框（`[x] `）；
- **优雅溯源注解**：内容末尾自动附加来源出处，如 `（源自笔记《2026-10-24 工作日记》）`，脉络一目了然且不繁冗。

### 3. 互动类型智能语义匹配 (`inferInteractionType`)
- **自动识别分类**：根据段落文字的语义，自动将转录互动匹配为精准的业务分类：
  - `吃饭/火锅/咖啡/下午茶` $\to$ 🍽️ **聚餐**（`meal`）；
  - `电话/致电/微信语音/电联` $\to$ 📞 **电话**（`call`）；
  - `微信/发消息/钉钉/飞书` $\to$ 💬 **消息**（`message`）；
  - `见面/开会/面谈/拜访/研讨` $\to$ 🤝 **见面**（`meeting`）；
  - `邮件/email` $\to$ ✉️ **邮件**（`email`）；
- 列表直观展现智能推测胶囊，点击一键转入对应分类。
