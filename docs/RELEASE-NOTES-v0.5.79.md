# v0.5.79 发布说明

发布日期：2026-10-26

## 核心亮点：思源文档深度双向咬合——日记文档互动自动双链追加、城市专题文档一键生成

本版本正式落地用户关于“组织、城市、日期等要与思源笔记文档深度联动，数据放入对应文档，双链进一步加深”之核心架构演进方案，完成了**日记、城市与人脉知识图谱的深度双向咬合**：

### 1. 记互动同步写入思源当日日记文档（Daily Note Deep Linking）
- **告别日记与人脉割裂**：在快捷记互动弹窗（`QuickRecordDialog`）中新增「同步写入思源当日日记文档（带人物双链）」选项（默认勾选）；
- **原生双链自动追加**：记录互动后，自动通过思源官方内核机制定位或创建当日日记文档，向日记追加格式化事项：
  `- 🤝 14:30 与 [张三](siyuan://blocks/personDocId) 见面：沟通了合作方案`；
- **思源图谱与反链瞬间闭环**：当天的日记文档直接产生了指向人物的块链接，人物详情页的反链（Backlinks）视窗与思源全局关系图谱无缝自动连通！

### 2. 城市人脉实体专题文档一键生成（City Topic Document）
- **城市一等公民化**：在「城市人脉与行程助手」中新增「生成/更新思源城市文档」动作；
- **知识网络星系聚类**：一键在当前笔记本中生成《城市人脉 · {城市名}》文档（带有 `custom-lvct-city` 属性），自动整理同城常驻好友与关联机构双链，在思源笔记知识图谱中形成以城市为枢纽的星系聚类拓扑。
