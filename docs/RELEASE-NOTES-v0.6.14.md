# v0.6.14 发布说明

发布日期：2026-10-28

## 核心亮点：名片隐私保护盾设置项持久化与全渠道用户自主控制（Privacy Shield Preferences）

本版本快速响应用户在实际使用中的高价值体验反馈——“名片私密信息离席自动遮罩盾，可以设置开启或取消。有的人并不需要遮挡”：

### 1. 设置页全局默认开关（ViewPreferences.privacyShieldEnabled）
- **默认关闭，清晰直读**：在偏好模型中增设 `privacyShieldEnabled` 字段，默认设为 `false`；对于日常在安全私密环境办公、不需要遮挡的用户，所有名片与图谱抽屉的电话、微信、邮箱保持明文直读，零多余操作；
- **设置页自由开关**：在“设置与数据” -> “通用显示偏好”中新增 **「名片私密信息离席隐私保护盾」** 开关，需要防护的用户可随时一键全局开启或关闭，设置秒级持久化同步。

### 2. 详情页与图谱抽屉即时动态响应
- **默认状态跟随偏好**：人物详情页（`PersonDetail`）与关系图谱节点速查抽屉（`RelationGraph`）均以全局偏好为初始状态；
- **临时显形与随时切换**：
  - 开启后点击「隐私盾」可随时触发 5 秒临时显形（带微秒倒计时反馈）；
  - 不需要遮罩的用户可随时在设置中取消，满足不同用户群体在不同工作环境下的差异化隐私需求。
