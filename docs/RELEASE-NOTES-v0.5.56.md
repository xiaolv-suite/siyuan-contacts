# v0.5.56 发布说明

发布日期：2026-10-25

## 核心亮点：会面简报融合笔记反链提及、反链摘要一键导出与深度知识互联

本版本进一步拓展了人脉往来数据与笔记知识图谱的深度与广度融合场景：

### 1. 会面简报整合笔记反链提及 (`## 笔记与日志提及`)
- **零碎要点不遗漏**：会面简报（Meeting Briefing）导出时，自动将全知识库中最近在日记或工作随笔里对该联系人的双链引用段落作为独立分区导出；
- **携带原日记块引**：简报中清晰注明出处并嵌入思源深度定位链接（形如 `[《2026-10-24 工作日记》](siyuan://blocks/xxx)`），去见朋友前导出一份简报，过往全部零碎细节随身带；
- **支持按需勾选排除**：简报生成器支持自由勾选是否包含反链提及分区。

### 2. 反链视窗一键导出全部反链摘要
- 反链视窗右上角新增 **`<Copy> 复制反链摘要`** 动作；
- 点击一键将当前过滤后的全部笔记反链汇总为工整清晰的 Markdown 列表复制到剪贴板，伴随平滑绿色的 `已复制反链摘要 ✓` 成功微反馈。
