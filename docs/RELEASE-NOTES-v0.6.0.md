# v0.6.0 里程碑大版本发布说明

发布日期：2026-10-27

## 核心亮点：小驴全生态超级联邦、人脉常识闪卡互通与知识沉淀里程碑

**小驴人脉（Lv Contacts）正式迈入 6.0 时代！**
本版本作为 2026 年度里程碑大版本，全面贯彻落实《小驴全生态联邦协同与排雷规范》与战略演进蓝图，打通了全生态跨插件渐进知识流通通道，并集聚了近期核心能力的全面蜕变：

### 1. 全生态超级服务桥与渐进学习双向贯通（Ecosystem Federation v2）
- **小驴拾遗联动（观点渐进归档）**：在公开服务桥 `window.LvContacts` 中正式上线 `appendFact` 与 `getFacts` 协议能力。用户在小驴拾遗中漫游阅读行业深度研报、专访或新闻时，选中文本即可一键将该段见解作为带时间戳与出处的事实记录追加至对应人物文档中；
- **小驴闪卡联动（常识记忆闪卡）**：在人物事实画像卡片增设「✨ 一键制成常识闪卡」，一秒生成标准 Q&A 问答文本，推入小驴闪卡队列通过 FSRS 算法对抗遗忘，让重要客户的饮食禁忌、偏好习惯与关键背景永远铭记于心。

### 2. 集聚 v0.6.0 时代全方位核心能力基座
- 🕸️ **关系图谱拓扑**：交互式边图例直接过滤边、320px 节点右侧轻量速查抽屉（Node Quick Drawer），拓扑心流不中断；
- 🏙️ **城市人脉网络**：正式市级文档受控区块同步与后台防抖增量受控刷新（City Topic Auto-Rebase），严格隔离保护手写攻略笔记；
- 🎨 **多主题色彩方案**：暖干邑橙、生机翡翠、深海蔚蓝、极光紫罗兰、暗金落叶 5 大高阶配色预设与设置页即时调色盘换肤；
- 📇 **全要素通讯录互通**：vCard 3.0 / RFC 6350 全要素双向保真（微信号 `X-WECHAT`、常驻城市 `ADR`、组织 `ORG`、职位 `TITLE`），手机原生通讯录完美呈现；
- ✨ **智能关联挖掘**：基于同场活动与共同组织计算亲密度，智能发现弱联系好友对并支持一键在双方文档追加双链正式建链；
- 📖 **知识沉淀仪式**：交往回顾一键沉淀为思源实体文档《人脉交往回顾 · YYYY-MM-DD 至 YYYY-MM-DD》，深度融入思源双链网络。
