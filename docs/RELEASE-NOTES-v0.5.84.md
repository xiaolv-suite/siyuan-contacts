# v0.5.84 发布说明

发布日期：2026-10-26

## 核心亮点：思源文档融合深化——城市实体文档专属浮动档案条（City Doc Strip）与同城人脉筛选直达

本版本深入贯彻用户关于“继续强化与思源文档的融合”之核心演进方向，在人物文档、组织文档档案条的基础上，补全了三大实体中最后一块关键拼图——**城市实体文档专属浮动档案条**：

### 1. 城市实体文档专属浮动档案条（City Doc Strip）
- **城市实体文档智能感知与挂载**：用户在思源主编辑器中打开任何一篇城市文档（如《深圳》、《南京》、《杭州》等，带有 `custom-lvct-city` 属性）时，标题下方自动优雅注入城市专属浮动档案条；
- **琥珀金辉微浮雕徽标**：图标采用落叶琥珀金渐变配白光立体微浮雕（`lvct-strip__avatar--city`），直观呈现城市名称与常驻好友统计；
- **同城好友筛选与行程助手无缝直达**：
  - **`[同城好友]`**（Primary 暖橙主操作）：一键秒级拉起小驴人脉并在名册中精确筛选常驻该城市的全部好友；
  - **`[行程规划]`**：一键打开小驴人脉城市与行程助手，探索同省周边人脉、切换出差/出游/顺路场景并导出探访备忘录。

### 2. 人物、组织、城市三位一体全景闭环达成
至此，思源主编辑器对**人物文档（暖干邑橙）**、**组织文档（天青灵珠）**与**城市文档（落叶琥珀金）**三大知识图谱核心实体全部实现智能识别与专属浮动横幅挂载，双向穿透与文档流转体验无缝自洽。
