# v0.5.89 发布说明

发布日期：2026-10-27

## 核心亮点：群体活动日记双向双链自动追加、名册复杂条件流折叠收纳与人机工效学升维

本版本深入贯彻落实《小驴人脉后续开发总计划与演进路线图 (2026 - 2027)》第一阶段的核心目标，全面打通了多人活动在思源日记中的全员双链追加，并完成了名册条件流的折叠收纳：

### 1. 群体活动（Occasions）自动在思源当日日记生成全员双链追加
- **一次活动，全员穿透**：当用户登记多人聚餐、团队会议或朋友聚会（如“大湾区开发者晚宴”）时，插件自动定位或创建当天的日记文档，并追加全员事项：
  `- 🍽️ 活动：大湾区开发者晚宴 @ 深圳湾（与 [张三](siyuan://blocks/id1)、[李四](siyuan://blocks/id2)）`；
- **全生态反链瞬间咬合**：活动日记不仅记录在案，且日记文档同时产生了指向所有出席人的原生块引用，每位参与者的人物反链视窗均可精准溯源到当天的日记！

### 2. 名册复杂条件流平滑折叠与展开收纳（PeopleView）
- **多条件首屏视野保护**：当用户选定的生效筛选条件超过 4 项时，首行自动展示前 3 项高频胶囊，其余平滑收纳为 `+N 项 ▾` 交互胶囊；
- **清爽无晃动**：点击可就地平滑展开全部条件，收起即可复原，首屏纵向空间永远稳定规整，右侧始终保留醒目的珊瑚红危险动作 `[清除全部]`。
