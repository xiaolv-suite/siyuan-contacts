# v0.6.10 发布说明

发布日期：2026-10-27

## 核心亮点：关系图谱桌面级键盘快捷控制（Graph Keyboard Shortcuts）与度数直跳

本版本深入贯彻落实《小驴人脉后续开发总计划与演进路线图 (2026 - 2027)》关于高阶图谱拓扑控制台的规划，为全景关系网络引入了桌面级快捷键与度数切换控制：

### 1. 关系图谱桌面级快捷键全套支持（Keyboard Shortcuts）
- **缩放控制**：按 `+` / `=` 放大，按 `-` / `_` 缩小；
- **全景自适应**：按 `0` 自动居中自适应全部节点（`fit`）；
- **全屏展开**：按 `F` 瞬间切换大图全屏/还原；
- **重新布局**：按 `R` 触发当前布局引擎重排（`relayout`）；
- **度数直跳**：以人物/本人为中心时，按 `1` 聚焦一度直接关系，按 `2` 快速展开二度关联；
- **快速退出**：按 `Esc` 随手收起 320px 节点抽屉与悬浮信息卡；
- **无冲突智能屏蔽**：在节点搜索框或文本框键入时不截断普通字符输入。

### 2. 操作簇浮动工具提示强化
- 右下角 FAB 浮动按钮组标题增加快捷键标记，如 `适应 (0)`、`放大 (+)`、`缩小 (-)`、`重新布局 (R)`、`展开大图 (F)`，交互提示清晰自证。
