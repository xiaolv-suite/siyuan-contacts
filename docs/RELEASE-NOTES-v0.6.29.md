# v0.6.29 发布说明

发布日期：2026-10-28

## 核心亮点：联系人详情页「家庭与重要亲属关系树谱」（Family & Kinship Relationship Tree）

本版本将深受个人知识与人脉管理用户重视的家庭与亲属网络完整引入人物详情视窗，推出了结构清晰、温情直观的多层级亲属谱系管理系统：

### 1. 多层级亲属关系域模型与存储层（`domain/kinship.ts` & `data/kinship.ts`）
- **四大核心亲属层级分类**：
  - 👵 **长辈 / 父母（parent）**：记录父亲、母亲与长辈长亲；
  - 💑 **配偶 / 伴侣（spouse）**：记录妻子、丈夫或生活伴侣；
  - 🤝 **同辈 / 手足（sibling）**：记录兄弟、姐妹等同辈亲属；
  - 👶 **晚辈 / 子女（child）**：记录儿子、女儿与晚辈后代；
  - 🏠 **其他亲戚（relative）**：容纳姻亲、远亲等家族成员；
- **自管 JSON 存储安全可靠（`person-kinship.json`）**：
  - 遵循 Web Lock 临界区并发保护与写后回读严格校验；
  - 支持绑定已有联系人文档 ID（`linkedDocId`）形成双向穿透，或作为未建档家属轻量备忘。

### 2. 详情页家庭亲属谱系组件（`FamilyKinshipTree.svelte`）
- **层级卡片直观陈列**：在联系人概览页面以温情卡片形式分层归类呈现所有家属成员，包含称谓微标签、姓名、出生年/年龄及关键备忘；
- **双模态穿透与快捷录入**：
  - 若亲属已在名册建档，支持点击直达打开对应人物文档；
  - 底部提供紧凑录入表单，支持角色选择、细分称谓（如“长子”、“岳母”）、出生年与忌口/喜好备忘一键保存；
  - 支持单项快速移除与数据即时联动。
