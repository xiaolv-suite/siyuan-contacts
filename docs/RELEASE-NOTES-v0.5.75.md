# v0.5.75 发布说明

发布日期：2026-10-26

## 核心亮点：设计方案深化落地——企业级首字渐变徽标自适应生成、回收站过期胶囊与恢复微动效

本版本继续围绕用户“继续落地前期的规划”之核心指令，深入推进《全景 UI/UX 深度审查报告与系统性优化方案》关于视觉辨识度与回收站安全交互的开发落地：

### 1. 组织首字符企业级渐变微浮雕自适应生成（OrgsView）
- **无 Logo 组织首字符自适应提炼**：未上传 Logo 的组织卡片不再使用千篇一律的灰色小图标，而是自动提炼组织全称的首个汉字或英文词（如“清华大学”提炼“清”，“Apple”提炼“A”）；
- **绿松石天青微浮雕质感**：背景采用小驴辅色天青灵珠（`--lv-accent-cyan`）高阶双色渐变与白光立体投影，名册与组织全貌辨识度瞬间倍增。

### 2. 回收站安全交互与过期时效微胶囊（SettingsView）
- **剩余时效暖橙胶囊化**：回收站缓冲条目中的“剩余 N 天”由普通灰色文本升级为醒目的 `--lv-brand-soft` 暖橙微胶囊，过期提醒清晰直观；
- **恢复联系人微动作规范**：恢复按钮引入单色矢量 `<RotateCcw>` 与微触感，防误删安全体系更加体贴完善。
