# v0.6.13 发布说明

发布日期：2026-10-28

## 核心亮点：离席隐私保护盾（Privacy Mask Shield）与社交衰减失联预警（Cooling Alert）

本版本深入贯彻落实小驴快门中枢 Issue #146 针对社区优秀设计（离开即锁、岁时记/艾宾浩斯记忆模型）的落地建议，全面推出了名片隐私防护与社交衰减失联预警：

### 1. 名片私密信息离席自动遮罩盾（Privacy Mask Shield）
- **多维度私密信息安全遮罩**：联系人的私人电话、微信号、邮箱与私密资料支持一键开启隐私保护盾；
  - 手机号自动打码脱敏为 `138****5678`；
  - 电子邮箱安全遮罩为 `al***r@domain.com`；
  - 微信号自动脱敏为 `wx****88`；
- **5 秒倒计时自动重新隐去**：
  - 点击「隐私盾」即可临时显形并开启 5 秒倒计时（`已显形 (5s)`）；
  - 5 秒后自动重新掩盖遮罩，彻底杜绝在投屏、录屏或工位有人路过时泄露重要联系人隐私；
- **图谱抽屉与详情页双向覆盖**：
  - 联系人详情页（`PersonDetail`）与关系图谱 320px 节点速查抽屉（`RelationGraph`）全面支持隐私保护盾与安全复制。

### 2. 社交衰减失联预警徽标（Relationship Cooling Alert）
- **客观时间推导失联判定**：当人脉关系温度降至“渐冻（cold）”或逾期超期未联络时，联系人名片顶部呈现清晰的预警横幅：
  - `❄️ 关系已渐冻冷却 · 距上次联系已过去 N 天，建议主动问候联络`；
- **一键直达快速跟进**：点击预警横幅右侧的「记一笔互动」按钮，直接唤起交往时间流与记录输入框，助力用户即刻破冰维系高价值人脉。
