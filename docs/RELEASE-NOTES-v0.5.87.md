# v0.5.87 发布说明

发布日期：2026-10-27

## 核心亮点：设计方案深化落地——仪表盘人脉温度胶囊空态防误触保护与禁用微样式

本版本继续围绕用户“继续”之核心演进方向，全面落实《全景 UI/UX 深度审查报告与系统性优化方案》中关于首页仪表盘人脉健康温度分布卡片的交互防误触与无障碍体验：

### 1. 仪表盘温度微胶囊空态防误触保护（DashboardView）
- **零人数时精准禁用**：当温热、常温、微凉、渐冻或未互动某分类下人数为 0 时，对应胶囊自动禁用（`disabled={count === 0}`），彻底杜绝误点跳转至空名册列表带来的交互挫败感；
- **智能说明气泡提示**：鼠标悬浮在 0 人数胶囊上时，提示明确展示为 `当前暂无该温度联系人`（人数 > 0 时才显示 `点击在名册中查看...`）。

### 2. `.lvct-chip--empty` 禁用微样式规范（index.scss）
- **通用空态芯片标准**：为通用 Chip 建立 `.lvct-chip--empty` 规范，自动应用半透明度（`opacity: 0.42`）、默认箭头光标（`cursor: default`），消除悬浮微上浮，提供清晰明确的不可交互视觉信号。
