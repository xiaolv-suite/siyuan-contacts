# v0.5.90 发布说明

发布日期：2026-10-27

## 核心亮点：属性数据库字段智能匹配对齐与健康状态微浮雕自洽

本版本深入贯彻落实《小驴人脉后续开发总计划与演进路线图 (2026 - 2027)》第二阶段的关键特性，全面降低了数据库配置成本，并重塑了数据库健康状态卡片的微浮雕视觉规范：

### 1. 属性视图数据库字段映射「✨ 智能匹配列」一键语义对齐（SettingsView）
- **一键消除配置门槛**：在设置页“字段映射”配置区增设 **`[✨ 智能匹配列]`** 动作按钮；
- **多维度语义嗅探**：点击后自动扫描思源属性视图数据库中现有的列清单，根据“电话/手机/Mobile”、“微信/Wechat”、“生日/Birthday”、“分组/Group”、“标签/Tags”等中英文语义特征，秒级为所有缺失字段自动选中建议列 ID，无需用户在下拉框中反复翻找对照。

### 2. 数据库健康状态卡自控微浮雕与柔和边框（index.scss）
- **告别生硬纯底色**：`.lvct-settings__health` 接入小驴自控卡片微浮雕规范，包含柔和描边、自控圆角与内高光（`box-shadow: inset 0 1px 0 rgba(255, 255, 255, 0.4)`）；
- **标准色阶对齐**：完整态使用 `--lv-heat-warm`（生机翡翠绿）微底与边框，异常态使用 `--lvct-danger` 珊瑚红微底，深浅模式下均清爽协调。
