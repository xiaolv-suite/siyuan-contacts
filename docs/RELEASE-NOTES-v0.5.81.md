# v0.5.81 发布说明

发布日期：2026-10-26

## 核心亮点：思源文档融合深化——组织与城市实体文档一键直达、日记块双向穿透与快捷定位

本版本继续围绕用户“继续优化，继续强化与思源文档的融合”之核心演进方向，全面强化了组织、城市与日记块的直接互通穿透能力：

### 1. 组织卡片与看板「打开文档 ↗」无缝直达（OrgsView）
- **一键在思源主编辑器中打开组织文档**：组织卡片操作区与下方看板标题栏新增「打开文档 ↗」操作；
- **随时手写会议记录与组织随笔**：用户无论在组织全景还是架构看板，点击即可秒级在思源主编辑区打开该组织的思源实体文档，正文与人脉双向自由流转。

### 2. 城市文档生成后一键「打开《城市》文档 ↗」（RegionExplorerDialog）
- **无缝开始手写城市生活攻略**：在「城市人脉与行程助手」中同步生成某城市文档后，即刻提供醒目的「打开《{城市名}》文档 ↗」入口；
- **打通城市人脉与生活笔记**：点击直接在思源主视窗打开该市级城市文档，用户随时在人脉列表上方或下方撰写餐厅推荐、常住酒店与出差生活备忘。

### 3. 时间线「原文」链接支持 Ctrl+点击直接定位日记块（PersonDetail）
- **双向深层穿透**：往来历史时间线与反链视窗中的「原文 / 复制块引」按钮，除一键复制 `siyuan://blocks/{id}` 外，支持按住 `Ctrl` 点击直接在思源中平滑定位打开原笔记段落，思源日记与人脉互动彻底融为一体。
