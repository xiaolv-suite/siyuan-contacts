# v0.6.27 发布说明

发布日期：2026-10-28

## 核心亮点：全库人情礼尚往来大账本与实体账簿沉淀（Central Exchanges & Gifts Ledger Hub）

本版本将具有深厚人情与社交温度的“礼尚往来/人情帮扶/资金收支”提升至首页全局中枢视角，推出了全库人情往来总览与思源实体账簿沉淀系统：

### 1. 全库人情往来汇算引擎（`domain/exchanges-summary.ts`）
- **多维度往来聚合分析（`computeExchangesSummary`）**：纯函数零外部依赖，严格聚合全库往来记录：
  - 📊 **核心指标大盘**：统计总笔数、待处理/待还礼（`open`）笔数、已结清/已答谢（`settled`）笔数；
  - 🎁 **类型与收支拆解**：智能区分礼品（`item`）、款项/礼金（`money`）、人情帮扶（`favor`）三类，统计累计收到与送出/借出资金总额；
  - 👥 **自动关联人物映射**：将每笔往来精确关联至对应联系人，自动提取待答谢事项清单；
- **思源标准实体账簿组装（`buildExchangesLedgerMarkdown`）**：自动生成带指标大盘、待办任务复选框 `- [ ]`、人物反链 `(( docId '姓名' ))` 与 Markdown 完整明细表格的实体账簿。

### 2. 首页仪表盘人情大账本抽屉窗口（`ExchangesHubDialog.svelte`）
- **操作栏全局入口**：仪表盘今日行动头部增设 **`[🧧 人情账本]`**；
- **状态筛选与即时处置**：支持按“全部/待处理/已结清”和“礼品/款项/人情”秒级点选筛选，支持直接在列表上一键切换结清状态；
- **一键沉淀思源账簿文档**：一键在当前笔记本创建 `/人情账本/🧧 人情礼尚往来大账簿 · YYYY-MM-DD`，生成完成后提供轻量横幅提示与 **`[在主编辑器打开 ↗]`**。
