# v0.5.49 发布说明

发布日期：2026-10-25

## 核心亮点：反链已转录跨会话永久记忆、关键词实时检索与批量转录合并防抖

本版本深入打磨反向链接视窗的跨会话生命周期与大知识库检索性能，带来更智能、更顺手的人脉知识沉淀体验：

### 1. 反链已转录状态跨会话永久记忆
- **天然跨会话记忆**：在 `TimelineItem` 与时间线引擎中透传 `externalRef`；
- **重启与重开零重复**：当再次打开人物详情弹窗或重启思源笔记后，系统直接从历史落盘事件中秒级匹配 `block:${blockId}`，历史已转录的反链条目自动永久保持 `✓ 已转互动` 状态，待转入条数 100% 精确，绝不出现老数据被重复误列为“待转入”的问题。

### 2. 反链视窗即时关键词搜索与形态分类
- **即时检索**：反链视窗顶部新增内联搜索框，输入关键字即可实时过滤反链段落内容、来源日记标题或日期（如快速检索“方案”、“合同”或“火锅”）；
- **形态分类胶囊**：提供 `全部`、`🔗 双链`、`💡 提及` 快速切换筛选与匹配计数，多反链场景下秒级定位目标记录。

### 3. 批量转录合并落盘防抖 (`skipDocSync`)
- 在「⚡ 全部转为互动」批量入库时，循环内部启动 `skipDocSync: true` 合并保护，完成全部事件追加后统一执行一次文档正文落盘，消除多余写放大，批量性能提升数倍。
