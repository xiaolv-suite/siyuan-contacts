# 小驴人脉 · 同类产品深度调研与 P0 核心功能落地技术规约

> **适用仓库**：`小驴人脉/siyuan-contacts/` (`siyuan-contacts`)  
> **对标产品**：Clay (个人 CRM 天花板)、Dex、Monica CRM、Obsidian People Notes  
> **核心哲学**：一人一文档结构化沉淀，化被动通讯录为主动“社交资产与温度管理”，实现见面前 3 分钟从容破冰。

## 二、 P0 级别建议加入的核心功能技术方案

### 功能 1：邓巴圈层维系节奏与失联温度计（Reconnection Cadence & Thermometer）
- **功能逻辑**：
  - 每个人物打标圈层（邓巴同心圆）：
    - `核心死党/重要客户`：期望间隔 14 天；
    - `常联伙伴`：期望间隔 30 天；
    - `泛行业人脉`：期望间隔 90 天；
  - 系统根据该联系人最近一条互动记录（交互流水）的更新时间，自动推导**关系温度**：
    - 🔥 **火热 (Hot)**：在周期内且近期有高频互动；
    - 🍃 **温和 (Normal)**：在周期内；
    - ❄️ **临界失联 (Cooling)**：已超期 1-7 天，首页温和提示“该问候了”；
    - 🧊 **深度断联 (Frozen)**：超期 > 30 天。

### 功能 2：会前 3 分钟破冰备忘卡（Pre-Meeting Briefing Card）
- **功能逻辑**：
  - 线下约见或微信沟通前，点击人物卡片上的【破冰卡】按钮；
  - 弹出极简单屏卡片（不含杂乱元数据），专供 3 分钟速读：
    1. **关键角色与现状**：目前供职机构、近期关注的方向；
    2. **细节软事实**：配偶/孩子名字或年龄、家乡、喜好饮品（如只喝美式）、饮食禁忌（不吃海鲜）；
    3. **上次遗留线索**：上次交谈结束时对方提到的近期计划（如“上个月说在准备带家人去云南”）；
    4. **推荐破冰话题**：基于上次遗留线索一键生成的开场白建议。

### 功能 3：思源全域双链反链穿透聚合与共同经历时间线（Co-occurrence Backlinks）
- **功能逻辑**：
  - 人脉文档作为思源原生文档，拥有固定 `doc_id`；
  - 插件通过 SQL 遍历全库中引用了该人物文档的所有块：
    ```sql
    SELECT id, root_id, content, updated FROM blocks 
    WHERE ial LIKE '%((person_doc_id%' OR content LIKE '%((person_doc_id%' 
    ORDER BY updated DESC LIMIT 50;
    ```
  - 在人物主页底部自动渲染为可视化的【共同经历与会议时间线】，点击任一节点一键跳转回当时的项目笔记或会议纪要。
