## 候选功能详细卡片

### `IDEA-01`：块级精确定位与上下文高亮滚动跳转
- **是什么**：在 `openSiYuanDocument` 及所有相关跳转逻辑中，若目标是具体块（例如日记中的某条互动、正文中的特定受控段落），通过 `openTab({ app, doc: { id: blockId, action: ["cb-get-hl", "cb-get-context"] } })` 打开。
- **解决什么问题**：目前仅传递了 `{ doc: { id: docId } }`，当互动记录在数千字的长篇日记中时，用户点击跳转只能停在日记文档顶端，需要自行翻找该行，体验割裂。
- **影响哪类用户**：日记内容丰富、依赖双向追溯的真实沉浸用户。
- **预估成本**：低（仅需封装 `src/libs/open-document.ts`，增加可选 `targetBlockId?: string` 并按条件带上 action 数组）。
- **与现有功能重叠度**：无重叠，现有 `onOpenPersonDoc` 仅支持文档级，这是向下的自然延伸。

### `IDEA-02`：编辑器块内容拖拽置入人脉识别区
- **是什么**：在工作台名册顶部、人物详情页及快速识别弹窗增加 HTML5 Drag & Drop 监听区，接受来自思源笔记 protyle 拖拽的内容。
- **解决什么问题**：用户在查阅会议纪要或团队笔记时，希望能直接将某段文字或人员列表拖进插件右侧/弹窗直接捕获。
- **影响哪类用户**：桌面端大屏、双栏/三栏分屏工作流用户。
- **预估成本**：中（需兼容思源编辑器内部拖拽数据结构并在拖拽进入时提供视觉虚线框反馈）。
- **与现有功能重叠度**：与快捷键/右键菜单识别资料属于同一处理内核的不同交互触发入口。

### `IDEA-03`：全量剔除 Lucide 第三方库，收口思源本体原生 SVG 图标
- **是什么**：将目前 40+ Svelte 组件中通过 `@lucide/svelte` 引入的图标全部替换为思源笔记标准的 `<svg class="b3-menu__icon"><use xlink:href="#icon..."></use></svg>` 原生图标机制。
- **解决什么问题**：彻底解决第三方图标线宽与宿主不一致、深色主题跟随延迟、包体积冗余等问题，达到“与宿主完全一致，避免插件看起来像外挂”的极致质感。
- **影响哪类用户**：全体用户，尤其是在高对比度、不同宿主自定主题下使用的用户。
- **预估成本**：高（涉及 40 余个组件的逐一核对与替换，且需要确保思源所有对应图标 symbol 存在或优雅 fallback）。
- **与现有功能重叠度**：纯视觉展现与依赖净化重构。

### `IDEA-04`：首页年度热力图方格即时悬浮互动气泡
- **是什么**：为 `ActivityHeatmap.svelte` 中的日期格子增加轻量级无延迟浮动提示，悬浮时直观展示当日交往人员姓名标签与互动类型徽标。
- **解决什么问题**：目前仅依赖浏览器原生 `title` 属性，响应延迟且排版单一。
- **影响哪类用户**：注重足迹回顾的高频交往用户。
- **预估成本**：低（0.5天）。
- **与现有功能重叠度**：纯微交互增强。

### `IDEA-05`：首页关注摘要支持永久默认折叠偏好
- **是什么**：在 `ViewPreferences` 中增加 `dashSummaryDefaultCollapsed?: boolean`，并在设置页提供切换开关。
- **解决什么问题**：允许不需要大横幅的用户默认收拢摘要区，留给行动清单更多垂直空间。
- **影响哪类用户**：小屏笔记本或追求极简信息密度的用户。
- **预估成本**：低（0.5天）。
- **与现有功能重叠度**：用户自定义偏好增强。

### `IDEA-06`：名册卡片支持自定义多字段展示与排序预设
- **是什么**：在视图配置或设置中增加「卡片主副字段显隐」，允许勾选是否在卡片常驻呈现城市、生日、所属部门、最近互动等字段。
- **解决什么问题**：满足商务、HR、校友会等不同场景用户对卡片信息优先级的个性化诉求。
- **影响哪类用户**：名册规模较大（>100人）且关注多维属性的进阶用户。
- **预估成本**：中（1.5天）。
- **与现有功能重叠度**：对现有详细/紧凑卡片的配置延伸。

### `IDEA-07`：会前破冰简报导出为思源 Callout 引述块
- **是什么**：在 `PersonDetail.svelte` 的「⚡ 会前 30 秒速览」增加复制为 `>>>` 或带图标引述块的选项。
- **解决什么问题**：便于用户把忌口红线、近期互动要点、熟人背景作为“会前备忘”直接贴在会议纪要笔记头部。
- **影响哪类用户**：会议纪要规范化、重度笔记用户。
- **预估成本**：低（0.5天）。
- **与现有功能重叠度**：对现有复制纯文本的格式化增强。

### `IDEA-08`：关系图谱按组织/标签隔离子网与矢量 SVG 导出
- **是什么**：在关系图谱工具岛增加「导出为 SVG / PNG」按钮，将当前 Cytoscape 视图导出为清晰矢量图形。
- **解决什么问题**：满足用户将人脉关系拓扑图嵌入月度汇报、PPT 或复盘文章的需求。
- **影响哪类用户**：团队管理者与人脉知识库建设者。
- **预估成本**：低（0.5天）。
- **与现有功能重叠度**：对现有纯 Markdown 导出的视觉形态补充。

### `IDEA-09`：数据健康体检单项缺陷一键直达修补
- **是什么**：在健康体检报告中，为每一项异常提供单项「直达修复」跳转按钮，点击后自动定位目标人物并预填建议值。
- **解决什么问题**：消除用户看到体检异常项后，需要手动记录姓名并去名册搜索修改的繁琐路径。
- **影响哪类用户**：定期做数据治理的高阶用户。
- **预估成本**：中（1天）。
- **与现有功能重叠度**：对体检报告的行动化闭环增强。

### `IDEA-10`：名册搜索单唯一匹配项回车直达详情
- **是什么**：在名册桌面端搜索框（`input.lvct-people__desktop-search`）中，当实时过滤结果数组 `filtered.length === 1` 且搜索词非空时，用户敲击 `Enter` 键直接调用 `openDetail(filtered[0])` 打开该联系人详情弹窗。
- **解决什么问题**：打字输入联系人姓名或电话后，往往已经能精准定位到唯一人物，此时仍需伸手移动鼠标去点击卡片，或者按 Tab 多次移动焦点，割裂了纯键盘操作的连贯性。
- **影响哪类用户**：全键盘操作流、盲打高频检索联系人的深度记录用户。
- **预估成本**：低（0.5天）。
- **与现有功能重叠度**：无重叠（目前 Enter 仅在 `filtered.length === 0` 时打开新建联系人向导，当 `filtered.length === 1` 时无任何键盘响应）。

### `IDEA-11`：关系图谱悬停一阶邻居聚焦与无关节点动态淡出
- **是什么**：在 Cytoscape 画布中，当鼠标悬停某个节点（或键盘获得焦点）时，自动将该节点及其直接相连的一阶邻居与相连边保持高亮，全图其余无关节点和连线动态淡出（设置 `opacity: 0.15`）；移开鼠标后平滑恢复原状。
- **解决什么问题**：当网络规模稍大（>50 节点）时，线条密集交错成蛛网状，肉眼很难在全局中一眼分辨出当前节点究竟直接连着谁、所属的微圈子边界在哪里。
- **影响哪类用户**：中大型人脉网络（>50人）、高频查阅网络拓扑的进阶用户。
- **预估成本**：低（0.5天，基于 Cytoscape 节点 `mouseover`/`mouseout` 事件对 `node.neighborhood()` 和其他元素打 class 即可）。
- **与现有功能重叠度**：否（现有仅在点击单条边时显示证据抽屉，节点 hover 仅弹悬浮卡，画布本身无全图聚光灯联动）。
