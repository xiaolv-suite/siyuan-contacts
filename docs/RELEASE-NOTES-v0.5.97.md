# v0.5.97 发布说明

发布日期：2026-10-27

## 核心亮点：vCard 通讯录全要素双向高保真互通（微信、常驻城市、组织与职务）

本版本深入贯彻落实《小驴人脉后续开发总计划与演进路线图 (2026 - 2027)》第二阶段关于通讯录与外部协议互通的关键规划，全面升级了 vCard 导入导出引擎：

### 1. vCard 3.0 全要素双向高保真互通（vcard.ts）
- **微信与城市保真**：全面支持微信号（`X-WECHAT`）与常驻城市（RFC 6350 标准 `ADR;TYPE=HOME:;;;;{city};;`）的序列化与反向提取；
- **组织与职务规范**：完整保留所属机构（`ORG`）与任职职位（`TITLE`），导入导出往返无损；
- **手机系统通讯录完美适配**：导出的 `.vcf` 导入至苹果 iOS 通讯录、华为、小米等智能设备时，姓名、电话、微信、城市与职务均可被原生通讯录即时识别呈现。

### 2. 服务层导出智能映射（exportVcfText）
- **多源智能提炼**：自动提取联系人的规范化常驻城市与任职档案，平滑映射为 vCard 标准字段，无需手动补录；
- **子集导出高保真**：无论是全量导出、当前筛选范围导出、还是勾选部分联系人导出，均享受全要素高保真输出。
