# v0.6.3 发布说明

发布日期：2026-10-27

## 核心亮点：复合斜杠命名原生支持（#19938）与地理位置字段契约扩充（#20325）

本版本深入贯彻落实《小驴全生态联邦协同与排雷规范》中枢第三期关于思源最新内核特性的深化建议，实现了联系人命名自由度与地理数据契约的全面升级：

### 1. 联系人复合斜杠命名原生支持（Composite Slash Naming）
- **思源 3.8.8+ 解除斜杠限制适配**：全面解除旧版对斜杠字符的硬性阻断校验。联系人姓名现在可以直接使用如 `张三 / 某某科技CTO`、`李四 / 咨询顾问`、`Alice / Designer` 等复合形式命名；
- **路径段安全防裂转义（sanitizeHPathSegment）**：在生成思源文档人读路径（hpath）时，底层自动将半角斜杠安全转义为全角斜杠 `／`（Unicode `\uFF0F`），彻底避免思源文件树将其误切分为多级子目录，而在文档标题（Heading）与属性数据库中完整保留原版半角斜杠；
- **控制字符严格防线**：对换行符、制表符、NUL 等不可见破坏性控制字符保持严格拦截。

### 2. 属性数据库原生地理位置字段契约扩充（Location Field Support）
- **官方 location 控件对齐**：在 `AvFieldType` 底层字段类型中扩充登记思源官方原生地理位置列类型 `"location"`（#20325）；
- **向后兼容与对账自愈**：初始化建库、字段健康检查与手动字段映射平滑适配官方 location 字段，为后续空间地理热力分布图谱奠定稳固契约底座。
