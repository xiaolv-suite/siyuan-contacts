# v0.5.99 发布说明

发布日期：2026-10-27

## 核心亮点：人脉交往周期回顾思源实体文档沉淀（Review Doc Generator）与仪式感复盘

本版本深入贯彻落实《小驴人脉后续开发总计划与演进路线图 (2026 - 2027)》关于人际交往周期检视仪式与本地知识沉淀的关键规划，上线了交往回顾文档一键沉淀功能：

### 1. 人脉交往回顾实体思源文档沉淀（Review Doc Generator）
- **本地知识沉淀仪式**：在当前工作区笔记本一键生成《人脉交往回顾 · YYYY-MM-DD 至 YYYY-MM-DD》实体思源文档，告别报表“只在弹窗看一眼”的浅层交互；
- **多维度结构化聚合**：
  - 📊 **核心指标概览**：自动呈现互动人次、触达好友、独立活动场次、各来源分布及对比上周期的环比变化；
  - 🏆 **重点深交人脉**：自动提取高频互动联系人，带原生双链 `siyuan://blocks/` 点击直达；
  - 📅 **往来互动流水**：清晰记录日期、人物、多人同场活动标记与备忘细节。
- **思源原生融合**：文档打上 `custom-lvct-review` 受控属性，完全融入思源双链网络、全局检索与多端同步体系。

### 2. 报表弹窗即时流转与直达打开
- **即时沉淀主按钮**：在 ReviewReportDialog 底部增设「✨ 沉淀为思源文档 ↗」操作，秒级完成正文 Markdown 组装与落盘；
- **一键直达主编辑器**：生成成功后提供「在主编辑器打开 ↗」便捷动作，复盘与流转浑然一体。
