# v0.5.46 发布说明

发布日期：2026-10-25

## 核心亮点：全功能 E2E 深度排查、老用户历史数据零白屏加固与反链防重转录

本版本以真实用户使用动线为核心，全面执行了端到端全链路 E2E 深度排查，对老用户升级兼容性与边缘边界进行了彻底防御加固：

### 1. 老用户升级与缺省偏好零白屏防御
- **首页偏好缺省安全兜底**：修复老用户历史数据未初始化偏好配置时，首页读取 `preferences.birthdayWindowDays` 引发白屏崩溃的严重潜在缺陷，全面引入 `DEFAULT_VIEW_PREFERENCES` 默认兜底与链式保护；
- **容错空数组降级**：对仪表盘 `birthdays`、`allPeople`、`followUps` 等集合进行严格的空安全数组防护，彻底消除 `.filter` 读取未定义对象引发的假死崩溃；
- **提醒暂缓容错读取**：在处置“不再提醒”与“顺延”时，对暂缓存储读取进行安全降级包裹，防止因为单项异常导致整体处置流程受阻。

### 2. 互动反链视窗体验防重加固
- **一键转录防误触与即时微反馈**：用户点击「⚡ 转为互动」后，按钮即时平滑切换为绿色的 `✓ 已转互动` 并锁定禁用，杜绝用户多次误触导致重复创建相同的往来记录；
- **错误透明感知**：转录发生异常时直接透传提示，确保用户对每一次互动写入结果拥有 100% 确定性。

### 3. E2E 测试环境严苛标准与冲突重试
- **纯粹 Chrome 标准**：全链路剔除 Edge 浏览器，严格锁定 Google Chrome 执行无头隔离测试；
- **环境冲突自动重试**：当检测到开发端口占用或浏览器启动冲突时，自动进入 5 分钟安全等待重试机制，确保跨插件并发开发安全。
