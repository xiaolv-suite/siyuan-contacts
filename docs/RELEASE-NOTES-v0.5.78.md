# v0.5.78 发布说明

发布日期：2026-10-26

## 核心亮点：设计方案深化落地——「城市与行程助手」场景升维，涵盖出差、出游、路过探访与多维备忘

本版本深入贯彻用户关于“不一定是出差，也可能是出游、路过等，看看怎么更好的表述和规划”之重大产品场景洞察，对全插件的城市探索与行程规划体系进行了全面升维：

### 1. 「城市与行程助手」多场景行程模式升维（RegionExplorerDialog）
- **涵盖商旅、出游与途经探友**：弹窗重塑为「城市人脉探索与行程助手」，新增四大行程模式快速点选：
  - 📍 **全部探访**（综合好友分布全览）
  - 💼 **商务出差**（拜访客户、商务伙伴与行业同行）
  - ✈️ **度假出游**（旅行探友、聚餐小聚与假期打卡）
  - 🚗 **顺路途经**（高铁经停、短暂停留约杯咖啡）
- **自适应动态行程备忘录**：复制备忘录时，标题与副标题自动根据选定场景动态生成（如 `# ✈️ 出游好友小聚备忘 - 杭州`），生成的 Markdown 包含组织、角色、电话与微信，随身即用。

### 2. 全局文案与认知模型统合（DashboardView & PeopleView）
- **摆脱单一出差局限**：首页仪表盘卡片与名册工具栏统一命名为「城市与行程」，右上角跳转升级为「行程助手 >」，弹窗标题对齐「城市人脉与行程助手」，与英文版 `Cities & Trips` 严密呼应。
