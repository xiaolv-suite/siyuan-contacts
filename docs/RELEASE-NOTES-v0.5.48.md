# v0.5.48 发布说明

发布日期：2026-10-25

## 核心亮点：双链转互动交互跃迁——微调转入 (Inline Edit)、一键全部转录与折叠治理

在 v0.5.47 深度打通历史真实时间精准还原与语义提炼的基础上，本版本在人物详情互动 Tab 带来更强掌控力与更顺手的转录交互体验：

### 1. 内联微调转入面板 (Inline Edit)
- **就地微调自由度**：反链条目新增「微调转入」展开面板；
- **核心字段三位一体可改**：
  - 发生日期选择器（默认自动提取的日记真实历史日期，可随意调整）；
  - 互动类型切换器（🤝 见面、📞 电话、💬 消息、🍽️ 聚餐、✉️ 邮件、📝 其它）；
  - 备注内容输入框（默认已清洗去杂质且附带出处，可就地增删补充）；
- 用户点击「确认转入」，即刻按自己微调后的定制参数完成入库与正文落盘。

### 2. ⚡ 一键全部转录 (Batch Convert)
- **告别逐条点击**：反链视窗右上角自动统计待转录条数，呈现 `⚡ 全部转为互动（n）` 批量快捷动作；
- **全要素自动化**：点击一次，系统按各自识别的历史日期、智能语义分类与出处自动顺序批量转入，完成后批量按钮自动优雅隐藏。

### 3. 清爽折叠与待转入状态胶囊
- 支持点击反链标题随时折叠或展开（带 Chevron 动画与状态保持）；
- 标题旁清晰呈现 `n 条待转入` 橙色待办胶囊，直观掌握知识库中尚未归档的往来动态。
