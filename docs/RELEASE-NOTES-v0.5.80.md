# v0.5.80 发布说明

发布日期：2026-10-26

## 核心亮点：城市正式市级文档受控区块重塑与全局记互动日记双链全链路打通

本版本深入贯彻用户关于“城市就是正式的城市名，动态添加，按照城市（市级）为单位。这样这个文档也可以添加城市其他内容”之重大设计指示，并完成了全系统记互动日记双链自动同步：

### 1. 城市正式市级文档与受控区块架构重塑（City Topic Document）
- **正式市级城市命名规范**：城市文档直接以正式的市级城市名（如《深圳》、《南京》、《杭州》）作为文档标题，路径为 `/城市/{市名}`；
- **独立受控区块保护用户自由创作**：插件在城市文档内部仅通过带有 `custom-lvct-city-contacts` 属性的独立受控区块维护同城人脉与机构双链；
- **允许用户在该文档自由追加生活攻略**：用户可以在该城市文档的开头、末尾或中间自由手写常住酒店、美食攻略、商务走访随笔等任何内容，插件在同步时通过 `upsertMarkedBlock` 仅更新人脉受控区，**绝不覆盖抹除用户的任何手写笔记**！

### 2. 全系统记互动日记双链自动同步闭环（index.ts）
- **全链路自动同步**：在插件主入口的 `recordInteraction` 方法中，自动透传日记同步逻辑；
- **无论何处记录均无缝追加**：无论用户是在人物详情页概览记互动、在名册弹窗记互动、还是在首页行动清单中快捷记录，均自动且安全地在思源当天日记文档（Daily Note）末尾追加带有人物双链的原生事项（`- 🤝 14:30 与 [张三](siyuan://blocks/personDocId) 见面：沟通合作`），日记反链视窗与思源全局图谱全自动闭环咬合！
