# v0.6.25 发布说明

发布日期：2026-10-28

## 核心亮点：关系图谱时间轴演化回放滑块与网络生长动画（Social Graph Timeline Slider & Growth Evolution）

本版本将高阶网络分析软件（如 Gephi / Kumu）的时间切片回放能力引入小驴人脉关系图谱，推出了纯本地零依赖的时间轴演化回放系统：

### 1. 时间切片与网络演化算法引擎（`domain/graph.ts`）
- **客观时间戳推断与区间推算（`extractGraphTimeSpan`）**：
  - 纯函数零外部依赖，自动基于思源 14 位标准时间戳文档 ID 提取建档年份（从最早年份至当前年份）；
  - 自动生成连续的年度演进时序刻度；
- **核心时间切片演化过滤（`filterGraphByMaxYear`）**：
  - 严格按指定年份裁剪节点与两端关联边（只有当关联双方均已在该年份及之前建档产生联系时，关系连线才显现！）；
  - 实时重算当前时间切片下的节点度数，精准反映人脉网络的历史状态。

### 2. 关系图谱交互式演化播放器（`RelationGraph.svelte`）
- **工具栏快捷开启**：图谱操作区新增 **`[⏳ 时间演化]`** 切换按钮；
- **悬浮动态播放控制条（Timeline Player Bar）**：
  - 画布底端优雅居中悬浮控制条，包含 **`[▶ 播放 / ⏸ 暂停]`** 按钮、年份时间滑块、当前年份徽章与节点/关系实时统计；
  - 支持 **自动演化播放**：每秒自动按年递增，亲眼见证人脉网络从点到线、从星散到繁茂生长的震撼过程；
  - 支持拖动滑块任意定位历史年份，提供 **`[↺ 全部]`** 一键瞬间重置全图。
