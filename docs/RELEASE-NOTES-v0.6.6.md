# v0.6.6 发布说明

发布日期：2026-10-27

## 核心亮点：出差拜访与城市人脉探访实体文档一键沉淀（Trip Itinerary Doc Generator）

本版本深入贯彻落实《小驴人脉后续开发总计划与演进路线图 (2026 - 2027)》关于地缘人脉管理与实地出差拜访深度协同的要求，全面打通了出差拜访清单的实体文档沉淀通道：

### 1. 出差拜访与城市人脉探访实体文档沉淀（Trip Itinerary Doc Generator）
- **一键沉淀行程文档**：在城市与行程助手（`RegionExplorerDialog`）中新增「✨ 沉淀为行程文档 ↗」核心动作；
- **自适应 4 大行程场景**：根据当前所选的行程类型（💼 商务出差、✈️ 度假出游、🚗 顺路途经、📍 全部探访），自动在当前笔记本沉淀《商务出差人脉拜访清单 · 城市 · YYYY-MM-DD》实体思源文档；
- **任务复选框与人物双链深度聚合**：文档正文自动生成带原生任务复选框 `- [ ]` 的拜访清单，聚合好友原生双链 `siyuan://blocks/{docId}`、单位机构、电话与微信号；
- **直达主编辑器流转**：文档生成后界面即刻呈现「打开行程文档 ↗」直达入口，无缝进入思源主编辑器展开出差记录。
