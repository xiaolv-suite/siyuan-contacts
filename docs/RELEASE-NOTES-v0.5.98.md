# v0.5.98 发布说明

发布日期：2026-10-27

## 核心亮点：潜在人脉关联智能挖掘（Potential Connection Discovery）与一键双向建链

本版本深入贯彻落实《小驴人脉后续开发总计划与演进路线图 (2026 - 2027)》第三阶段的关键特性，在本地端构建了基于共现图算法的人脉关联挖掘引擎与快速建链交互：

### 1. 潜在人脉关联智能挖掘算法引擎（connections-discovery.ts）
- **本地零 AI 依赖挖掘**：全自动扫描全库多参与者活动同场出席事实与共同所属机构，智能识别频繁产生交集但尚未在名册中建立正式关系的好友对；
- **智能亲密度评分与解释**：按同场活动与共同组织加权打分，提供「共同出席 N 次活动 · 共同从属某机构」等透明可解释的推荐理由；
- **自动防呆过滤**：严格排除已建链人物对、自环与本人档案，避免无效推荐。

### 2. 仪表盘轻奢 Bento 交互与一键正式建链
- **即时发现徽标**：在仪表盘今日行动区增设「✨ 潜在关联发现」动作徽标，即时感知网络弱联系候选；
- **一键双向建链**：专属发现面板支持一键正式建链，秒级在双方思源人物文档中追加原生双向链接，并同步更新属性视图数据库与关系图谱。
