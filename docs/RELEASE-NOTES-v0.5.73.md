# v0.5.73 发布说明

发布日期：2026-10-26

## 核心亮点：设计方案深化落地——概览往来直达锚点、图例自控高光与组织负责人标识纯化

本版本继续围绕用户“继续落地”指导指令，深度兑现《全景 UI/UX 深度审查报告与系统性优化方案》第二阶段设计落地项：

### 1. 人物详情概览页增设「全部往来历史」直达锚点（PersonDetail）
- **消除切 Tab 找寻成本**：在概览 Tab 的“最近互动”卡片右侧，直接增设轻量按钮 **`全部 {n} 条往来 >`**；
- **平滑无缝锚定**：点击秒级平滑切换到“互动”Tab，让用户从概览一瞥到详阅全部往来事实无任何阻隔与断点。

### 2. 关系图谱底栏图例完全自洽（RelationGraph）
- **图例高光与自控色阶**：底栏各图例项彻底清理 `--b3-theme-*` 残留，全面接入 `--lv-brand` 暖干邑橙激活高光与立体阴影，悬浮与点选过滤反馈更加清晰。

### 3. 组织看板负责人徽章自洽化（OrgsView）
- 组织成员列表中“负责人”标识全面接入自控 `--lv-heat-cool`（落叶琥珀金）徽章体系，色调与全插件设计系统浑然一体。
