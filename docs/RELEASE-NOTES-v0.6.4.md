# v0.6.4 发布说明

发布日期：2026-10-27

## 核心亮点：气泡式交往互动时间轴（Dialogue Bubble Timeline）与微触感体验升维

本版本深入贯彻落实《小驴全生态联邦协同与排雷规范》关于人际互动温润感与聊天微交互体验的建议，全面重构了联系人详情页中的交往互动时间流：

### 1. 气泡式交往互动时间轴（Dialogue Bubble Timeline）
- **微图标气泡徽章**：将生硬的时间线节点升级为带微图标的气泡指示徽章（`lvct-bubble-badge`），按活动类型（☕ 咖啡/聚会、🍱 用餐、📞 电话、📝 纪要等）展示生动的专属视觉符号；
- **拟物微卡气泡主体**：采用现代对话气泡几何切角（`border-radius: 4px 12px 12px 12px`），配合 `color-mix` 双层微光晕与浮雕阴影，使每一笔拜访、会面与交集呈现亲切温暖的对话感；
- **信息层级分明**：日期标签、类型胶囊、来源徽标、同场人数与原文块链接按视觉权重自然流转，右侧提供轻量级操作区；
- **深浅色无缝自洽**：完美适配思源官方及第三方浅色、深色主题与高对比度模式。
