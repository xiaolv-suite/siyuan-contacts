# v0.5.66 发布说明

## 核心亮点：逐页面微观空间秩序重塑——首字母索引条品牌高光、设置页面板 28px 呼吸呼吸感与深层自洽

本版本深入贯彻用户“每个页面都需要梳理，而非大面上的”指导原则，逐个对名册首字母栏、设置面板、图谱查询等子页面的微观交互空间进行精修：

### 1. 联系人名册首字母索引条微观重塑（`lvct-people__alphabet-btn`）
- **告别宿主灰色**：清理首字母按钮中依赖宿主灰色主题的残留，改用自控 `--lvct-text-2`；
- **小驴专属暖橙高光**：鼠标悬浮呈现暖干邑橙柔和底色，激活选中态呈现深邃暖橙填充与立体微投影（`box-shadow: 0 1px 4px rgba(234, 88, 12, 0.3)`），字母跳转节奏格外清晰。

### 2. 设置页面空间秩序与导航项重构（`SettingsView`）
- **舒适的 28px 面板内边距**：设置内容卡片（`.lvct-settings__panel`）内边距优化为 28px，搭配纯净白底与微浮雕投影；
- **设置子导航项小驴品牌对齐**：激活项接入暖干邑橙微底与内高光，整体与工作台主导航风格严丝合缝。
