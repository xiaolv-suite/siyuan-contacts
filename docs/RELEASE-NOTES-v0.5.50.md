# v0.5.50 发布说明

发布日期：2026-10-25

## 核心亮点：思源文档顶部档案条直接记互动、原地即时刷新与 QuickRecordDialog 闭环

本版本彻底打通了思源笔记“一人一文档”工作流与即时人脉互动的最后一公里闭环：

### 1. 人物文档档案横幅条直接记互动 (`+ 记互动`)
- **文档即 CRM 动作中心**：当用户在思源笔记中打开任何联系人的专属文档时，标题下方的档案横幅条新增 **`记互动`** 动作按钮；
- **随时随地就地记录**：阅读或编辑好友笔记时，无需特意切换跳转去人脉插件主面板，点击直接唤起轻量记互动弹窗；
- **原地即时刷新**：保存互动后，系统自动同步更新笔记正文的 `## 往来记录`，并且档案横幅条上的“最近互动几天前”与关系温度立即无刷新原地重算！

### 2. 紧凑轻盈的 QuickRecordDialog 弹窗
- 支持分类快速点选（🤝 见面、📞 电话、💬 消息、🍽️ 聚餐、✉️ 邮件、📝 其它）；
- 支持指定发生日期（默认今天，可点选调整）；
- 自动聚焦文本输入框，支持 `Ctrl+Enter` / `Cmd+Enter` 快捷键瞬间保存，`Esc` 随手关闭。
